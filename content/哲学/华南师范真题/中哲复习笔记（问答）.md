## 一、先秦

### Q1 〔北15/17/18/19/20；西电25；华侨09/16〕 孔子的仁与礼是什么关系？"一以贯之"指什么？

**答题要点**

1. **仁是礼的内核**："克己复礼为仁"（《颜渊》）；"人而不仁，如礼何"（《八佾》）——礼须有仁作依据。
2. **仁即爱人**，落实为忠恕："己欲立而立人，己欲达而达人"（忠）、"己所不欲，勿施于人"（恕）。
3. **一贯之道**：曾子以"忠恕而已矣"释"吾道一以贯之"（《里仁》）；朱熹解为"一本万殊"。
4. **为仁由己**："我欲仁，斯仁至矣"——道德主体性由此立。
5. **礼是仁的外化**：宰我问三年之丧，孔子以"心安"点破礼的根据（《阳货》）。
> **立论/易错**：勿把仁礼说成革命/保守二元对立；孔子**以仁释礼**，是"内在超越"的起点。正名、德政见 Q2。

### Q2 〔北10/15/17/18/25；华侨12〕 孔子的正名、德政与"天命靡常"

**答题要点**

1. **正名**："名不正则言不顺，言不顺则事不成"（《子路》）；君君臣臣父父子子——名分即秩序。
2. **正名非正字**：使名实相符、各守其分；荀子《正名》、法家"循名责实"皆由此出（见 Q46）。
3. **德政**："为政以德，譬如北辰"；"道之以德，齐之以礼，有耻且格"（《为政》）；庶—富—教。
4. **天命靡常**：《诗·大雅·文王》语，周公"以德配天"；孔子"畏天命"，天转为道德秩序。
5. **中庸**："过犹不及""执其两端，用其中于民"——德性与方法合一。
> **立论/易错**：正名是"礼崩乐坏"下的秩序修复，非逻辑学兴趣；天命靡常非宿命论。

### Q3 〔北10；华大25；华侨13/16/18〕 孟子的四端说与性善论的基本进路

**答题要点**

1. **四端**：恻隐（仁）、羞恶（义）、辞让（礼）、是非（智）之心，"人皆有之"（《公孙丑上》）。
2. **端非成品**："犹其有四体也"，须"扩而充之"，"苟能充之，足以保四海"。
3. **例证**："乍见孺子将入于井，皆有怵惕恻隐之心"，非为交情名誉，证善端先于功利。
4. **反证**："仁义礼智，非由外铄我也，我固有之也"；又以"平旦之气""夜气"说明本心可存养。
5. **与告子之争**：告子"生之谓性"，孟子以"犬牛之性犹人性与"驳之——争点是道德心能否还原为自然本能。
> **立论/易错**：孟子讲"善端"而非"性已完美"；性善是价值判断＋工夫起点。求放心、仁政见 Q4。

### Q4 〔北13/18/22/24；华侨09〕 孟子的仁政、求放心与民贵君轻

**答题要点**

1. **求放心**："学问之道无他，求其放心而已矣"——工夫是找回放失的本心。
2. **养浩然之气**："配义与道"，须"集义"而非"义袭"。
3. **仁政根据**："以不忍人之心，行不忍人之政"——性善是政治合法性基础。
4. **制民之产**："五亩之宅，树之以桑""勿夺其时"，使"黎民不饥不寒"；恒产→恒心。
5. **民贵君轻**："民为贵，社稷次之，君为轻"；王霸之别在"以德"与"以力"。
> **立论/易错**：仁政是"恒产—恒心—教化"的链条；"民贵"是价值排序，不等于现代民主。

### Q5 〔北14/21/23；华侨13/14〕 荀子的性恶论、化性起伪与隆礼重法

**答题要点**

1. **性伪之分**："人之性恶，其善者伪也"；性=本始材朴、不可学；伪=可学而能、可事而成。
2. **功能论证**：顺性则"争夺生而辞让亡"，故须师法礼义矫治——非经验上人全坏。
3. **化性起伪**：以礼义法度、积善改造人性；"涂之人可以为禹"。
4. **礼论**："礼者，养也"；礼起于欲与物的冲突，"明分使群"以防争。
5. **隆礼重法**："隆礼尊贤而王，重法爱民而霸"（《强国》）——教化与刑罚并用，开儒法合流之端。
> **立论/易错**：性恶是性—伪二元加"化"的可能；与孟子是"复其本有"与"矫其本无"之争（见 Q45）。

### Q6 〔北12/20/24；北26趋势〕 荀子的"天人之分"与"虚壹而静"

**答题要点**

1. **天行有常**："不为尧存，不为桀亡"；"明于天人之分"——天是自然而非有意志的神。
2. **制天命而用之**："能参"（与天地参）；由"知天"转向**控制自然**，中国哲学中少见的能动态。
3. **虚壹而静**："心何以知？曰虚壹而静"（《解蔽》）：虚=不以已藏害所将受；壹=不以夫一害此一；静=不以梦剧乱知。
4. **认知结构**："天官意物"（感官）→"心有征知"（理性）；"可以知，物之理也"。
> **立论/易错**：虚壹而静不同于庄子"心斋"式直觉，而是**有规范的认识论**；"分"不是对立而是"参"。

### Q7 〔北12/17/18/19/20/21/22/25；华侨15/16/17〕 老子的道、无为与"道法自然"

**答题要点**

1. **道有双重性**："道可道，非常道"不可言说；"有物混成，先天地生""道生一"又是生成本原。
2. **道法自然**：自然=自己如此；王弼注"道不违自然……在方而法方，在圆而法圆"（参 [[王弼的崇本息末学说]]）。
3. **反者道之动**："有无相生"；"弱者道之用"，守柔处下（"天下莫柔弱于水"）。
4. **无为**："道常无为而无不为"；不妄为、顺自然；"治大国若烹小鲜"。
> **立论/易错**："无"是"无"之用（"当其无，有车之用"）；"道法自然"非道上另有自然，河上公与王弼两读并存。

### Q8 〔北10/11/15/16/19/21/23/25；华侨17〕 老子的玄德、涤除玄览与"无名"

**答题要点**

1. **玄德**："生而不有，为而不恃，长而不宰，是谓玄德"（51 章）——生养而不占有、不主宰。
2. **玄德即自然**："莫之命而常自然"；不居功、不施恩，故不可见、不可名。
3. **涤除玄览**："涤除玄览，能无疵乎"（10 章，帛书作"玄鉴"）——洗去成见欲望，心如镜的观照。
4. **无名**："道常无名""无名之朴"；"名可名，非常名"——语言界限意识。
> **立论/易错**：玄览是**去蔽后的观照**而非神秘看光；"无名"不以名限道，非取消一切名。

### Q9 〔北15/17/20/21/22/23；华侨13/16〕 庄子的"齐物"与"道通为一"

**答题要点**

1. **齐是非**："彼亦一是非，此亦一是非"；是非起于"成心"与立场。
2. **吾丧我**：破除自我中心；"天籁"是万物各由其自性发声。
3. **道通为一**："恢恑谲怪，道通为一"；"天地与我并生，万物与我为一"。
4. **齐生死**："方生方死"，生死是气之聚散；"死生无变于己"。
5. **评价**：非"什么都对"的相对主义，而是**超越相对立场而体道**；代价是取消公共是非标准。
> **立论/易错**：齐物解认知之缚，逍遥得存在之自由（见 Q10）；勿等同于现代多元主义。

### Q10 〔北10/13/14/24/25；北26趋势；华侨14〕 庄子的逍遥、心斋坐忘与物化

**答题要点**

1. **逍遥无待**："至人无己，神人无功，圣人无名"；"乘天地之正……以游无穷"。
2. **小大之辩**：蜩与学鸠笑鹏，说明以己度人；大鹏亦"有待"（风），故须彻底无待。
3. **心斋**："唯道集虚……虚者，心斋也"（《人间世》）——听之以气，不以成心。
4. **坐忘**："堕肢体，黜聪明，离形去知，同于大通"（《大宗师》）。
5. **物化与寓言**：蝴蝶梦"不知周之梦为胡蝶与"；"寓言十九，重言十七，卮言日出"——文体即方法。
> **立论/易错**：心斋坐忘是**工夫**不是发呆；物化非"人生如梦"，而是物我相因、各适其天。

### Q11 〔北10/15/17/18/21/22/23/25；华大17/18；西电25；华侨09/14/15/16〕 墨子的兼爱、尚同与三表法

**答题要点**

1. **兼爱交利**："兼相爱，交相利"，爱无差等；与儒别：儒重亲亲有杀的差等与义，墨以"天志"与百姓之利为基。
2. **非攻**：杀一人谓之不义，攻国则谓之义，是"不知类"。
3. **尚同尚贤**：乱起于"一人一义"，故"选天下之贤可者，立以为天子"，逐级"一同天下之义"；尚贤破世卿世禄。
4. **三表法**："上本之于古者圣王之事""下原察百姓耳目之实""发以为刑政，观其中国家百姓人民之利"。
> **立论/易错**：墨家是"经验论＋功利主义"典型；三表第三表是实践检验雏形但不可等同马克思主义；尚同有权威主义风险。

### Q12 〔北15/16/17/18/19/22/23/24；华侨14〕 公孙龙与惠施：离坚白、白马非马

**答题要点**

1. **合同异（惠施）**："万物毕同毕异，此之谓大同异"；"天与地卑，山与泽平"——同异依参照系。
2. **离坚白**："视不得其所坚而得其所白……拊不得其所白而得其所坚"——坚、白可离石而独立。
3. **白马非马**："马者所以命形也，白者所以命色也"；求马黄黑皆可，求白马黄黑不可——外延与内涵之别。
4. **评价**：名家把语言—实在关系问题化；"诡辩"之名须重估（对勘 Q13、Q46）。
> **立论/易错**：白马非马是两个概念不等，不是常识否定；离坚白是属性分析，非否认石头。

### Q13 〔北10/11/13/14；华侨13/15〕 后期墨家的辩学、大故小故与"察类明故"

**答题要点**

1. **辩学**："辩，争彼也；辩胜，当也"；"以类取，以类予"——以"类"为推理单位，以"当"为胜负标准。
2. **故理类**："夫辞以故生，以理长，以类行者也"——论证需根据、条理、类推三要素。
3. **大故小故**：小故"有之不必然，无之必不然"＝必要条件；大故"有之必然"＝充足条件。
4. **察类明故**：察明物类、推明根据，是"非攻""兼爱"论证的方法论；"狂举"则是不合类、不拟实之推论。
5. **同异坚白**：墨家主"盈坚白"，与公孙龙"离坚白"对立；同有重、体、合、类，异有二、不体、不合、不类。
> **立论/易错**：大故小故须讲其"条件—结论"的反事实表述；2011 论述"后期墨家对辩论的看法"即考此。

### Q14 〔北10/12；北25（？）〕 韩非的法、术、势及其历史观

**答题要点**

1. **法**："宪令著于官府，刑罚必于民心"——成文、公开、赏罚必信，"法不阿贵"。
2. **术**："因任而授官，循名而责实"——驭臣之术，隐而不宣，核心是形名参同。
3. **势**："抱法处势则治"；势=权位，中人之主可借势而治。
4. **历史观**："世异则事异，事异则备变"；守株待兔之喻，反对"法先王"。
> **立论/易错**：法家把道德降为私人领域；秦亡后"阳儒阴法"成实际结构。2025 简答"韩非白马非马（原题如此）"当为公孙龙题误植（？），按 Q12 答。

### Q15 〔北10/13/15/17/19/20〕 黄老之学：心术、主术、静因之道与"前识"

**答题要点**

1. **黄老**：战国稷下至汉初思潮，托黄帝、宗老子，道法结合；《管子》四篇为代表文本。
2. **心术**："心之在体，君之位也"；"心术者，无为而制窍者也"——君无为而臣有为。
3. **主术**：君主南面驭臣之术，即"无为而制"；《淮南子·主术训》集大成。
4. **静因之道**："毋先物动，以观其则"；"因也者，舍己而以物为法者也"。
5. **前识**："前识者，道之华而愚之始"（《老子》38 章）；韩非释为"无缘而妄意度"。
> **立论/易错**：黄老是道的工具化、政治化；静因之道要求"舍己"以客观法则为准，非消极。

### Q16 〔北10/21/24/25；华侨09/15〕 《易传》的哲学贡献与阴阳五行

**答题要点**

1. **十翼**：彖象上下、系辞上下、文言、说卦、序卦、杂卦，共七种十篇；旧题孔子作，今认为战国儒家成书。
2. **一阴一阳之谓道**："刚柔相推而生变化"——辩证宇宙观的最早系统表述。
3. **形上/形下**："形而上者谓之道，形而下者谓之器"——道器之分成为宋明理气论的经学依据（见 Q39）。
4. **生生与日新**："生生之谓易""日新之谓盛德"；《大学》"苟日新，日日新"——儒家日新之化的源头。
5. **阴阳五行**：阴阳消长、五行生克，与《洪范》五行、《月令》合流，经董仲舒整合为天人体系（见 Q17）。
> **立论/易错**："形而上"原指有形之外，不等于西方 metaphysics；十翼非孔子亲笔，须标"旧说"。

## 二、两汉

### Q17 〔北10/12/17/18/21/22；北26趋势；华侨12/15〕 董仲舒的天人感应、大一统与性三品

**答题要点**

1. **天人感应**：天人同类，"以类合之，天人一也"；人副天数（"人之身，首员，象天容也"），天以灾异谴告人君。
2. **灾异谴告**："国家将有失道之败，而天乃先出灾害以谴告之"——以天限君，是"屈君而伸天"。
3. **大一统**："《春秋》大一统者，天地之常经，古今之通谊"；政治统一要求思想统一，"罢黜百家，独尊儒术"。
4. **三统三正与《春秋繁露》**：黑统/白统/赤统循环，建寅/建丑/建子三正迭用（《三代改制质文》）；《春秋繁露》为今文经学代表作。
5. **谶纬与评价**：谶书纬书以神学预言解经，董氏灾异说为先导；儒学由此神学化、制度化，也埋下王充批判的引线（见 Q18）。
> **立论/易错**：董氏之"天"是自然—伦理—政治一体的秩序总体，非简单人格神；评价须两分。性三品见 Q45。

### Q18 〔北24〕 王充的元气自然、疾虚妄与命定论

**答题要点**

1. **元气自然**："天地合气，万物自生"；天是"含气之自然"，无意志、不谴告——直接拆感应论。
2. **疾虚妄**：《论衡》以"疾虚妄"为宗旨；《订鬼》《论死》以"精神依形体"驳人死为鬼。
3. **命定论**：三命（正命、随命、遭命）；富贵贫贱由气禀与"时遇"决定——批判神学却走向命定。
4. **人性论**：《本性篇》主"性有善有恶"，善恶由气禀厚薄，中人以上可教（与董氏比较见 Q45）。
> **立论/易错**："疾虚妄"针对感应、谶纬、鬼神，非一般宗教情感；元气自然是宇宙论式"自然"，未到实验科学。

## 三、魏晋玄学与佛教中国化

### Q19 〔北10/11/12/14/15/17/18/20/23；华侨14/15〕 王弼的贵无、崇本息末与得意忘象

**答题要点**

1. **贵无以无为本**：《老子》40 章"天下万物生于有，有生于无"，王弼释为"以无为本"：无是"有之所以为有"的根据，有是末。
2. **崇本息末**："息"作**止息**解——治本则末自正，不必逐末；另有"养息/崇本举末"读法，本库 [[王弼的崇本息末学说]] 对《老子注》38 章有辨析。
3. **守母存子**："母，本也；子，末也。得本以知末，不舍本以逐末"（52 章）——守本体而不废现象。
4. **得意忘象**："得象而忘言，得意而忘象"——言象是工具，拘泥则失意，经典解释学方法论。
5. **名教出于自然**：仁义"发于内，为之犹伪"；名教本不坏，坏在刻意为之（见 Q40）。
> **立论/易错**：务必引原句，别只写"贵无"；"无"是无形无名而非不存在。裴頠、郭象回应见 Q40、Q20。

### Q20 〔北10/12/13/14/16/18/19/20/22/23/24；华侨13/14〕 郭象的独化、自生与性分

**答题要点**

1. **独化**："物各自造而无所待焉"；"块然自生""无故而自尔"——万物不由他物（也不由"无"）产生。
2. **自生**：反对"有生于无"与"以无为本"；生非他物所生，故因果不能追溯至第一因。
3. **性分**：万物各有"性分"，"各安其性分"即逍遥；大鹏小鸟各适其性，无高下——改造庄子小大之辩。
4. **名教即自然**：性分各足则名教与自然不冲突，为门阀秩序作本体论辩护（见 Q40）。
5. **批判生成论**：批"无"生有、批"有"待无，以"自尔"取消第一因追问；由本体论转向个体性—秩序论。
> **立论/易错**：独化是**反因果链条的生成论**，勿与唯物论混同；与莱布尼茨单子的类比只是启发性的（参 [[中国哲学总结]]）。

### Q21 〔北10/11/13/21/25〕 僧肇的《不真空论》《物不迁论》与般若三家义批评

**答题要点**

1. **不真空论**："不真"故"空"——万物非无而是假有；"即万物之自虚"，以中观纠正"本无"派偏空。
2. **物不迁论**："求向物于向，于向未尝无；责向物于今，于今未尝有"；"旋岚偃岳而常静，江河竞注而不流"。
3. **动静不二**：过去不至今，故"不迁"；非否认变化，而是变化中无常住自体迁移。
4. **三家义批评**：本无宗"情尚于无"、心无宗"无心于万物"、即色宗"色不自色"——皆未得缘起性空之实。
5. **影响**：以中国语汇消化中观，为三论、天台华严及宋明"空有""体用"思维奠基。
> **立论/易错**："不真空"是"不真"故"空"，不是"不真空"；物不迁最易被误读为不动论。

### Q22 〔北10/13/14/18/24；华侨15/16/17/18；华大17/18〕 佛教中国化：二谛、一心二门、一念三千、万法唯识与禅宗

**答题要点**

1. **二谛与性空**：真谛（空）俗谛（假有）不二；缘起性空，"八不"（不生不灭、不常不断、不一不异、不来不去）。
2. **一心二门**：《起信论》"依一心法有二种门：心真如门、心生灭门"；"不生不灭与生灭和合，非一非异"。
3. **一念三千与四法界**：天台"一念三千"（十界互具×十如是×三世間）；华严四法界（事、理、理事无碍、事事无碍）。
4. **万法唯识**："三界唯心，万法唯识"；唯识四分（相分、见分、自证分、证自证分）；有为法刹那生灭、相似相续。
5. **禅宗与重玄**：禅宗"自性即佛"（"佛是自性作，莫向身外求"）、"明心见性，顿悟成佛"（神秀渐修 vs 慧能顿悟）；成玄英等"重玄"——遣有遣无、双遣二边。
> **立论/易错**：中国化是格义—消化—创造三步，禅宗为典型；答理学渊源须点出"华严理事"与"起信一心二门"两线。

### Q23 〔华大17/18；华侨18；西电25〕 韩愈的道统说与李翱的复性书

**答题要点**

1. **道统**："尧以是传之舜……孔子传之孟轲，轲之死，不得其传焉"（《原道》）——对抗佛教法统的儒家谱系。
2. **排佛老**："博爱之谓仁，行而宜之之谓义"；《论佛骨表》以华夷之辨、政教利害立论。
3. **性情三品**：性分上中下，情亦三品；上者可教、下者畏威、中者待教而成。
4. **李翱复性**："性善情惑"——情昏而性匿；工夫是"灭情复性"（"妄情灭息，本性清明"），近佛教止观。
5. **理学先声**：道统提供正统性，复性提供工夫论；"性善情恶"直启宋明"天理人欲"之辨。
> **立论/易错**：理学"接着讲"的起点正是韩李；朱熹以"十六字心传"续道统（见 Q27）。

## 四、宋明理学

### Q24 〔北13/16/21；北26趋势〕 周敦颐《太极图说》的"无极而太极"、主静与人极

**答题要点**

1. **无极而太极**："太极动而生阳，动极而静，静而生阴"——太极→阴阳→五行→万物的生成序列。
2. **两种读法**：宇宙生成论（太极元气分化，马工程常见）；本体论读法（朱子："无极而太极"即"无形而有理"）。
3. **人极与主静**："圣人定之以中正仁义而主静，立人极焉"；自注"无欲故静"。
4. **诚**："诚者，圣人之本""五常之本，百行之源"——把《中庸》之诚提升为本体。
> **立论/易错**：周子之功在把宇宙论与心性论接通（天道—人道贯通）；无极太极之辩见 Q41。

### Q25 〔北10/11/12/13/15/20/21/24/25；西电25；华侨13/14/16〕 张载的"太虚即气"、"一物两体"与"民胞物与"

**答题要点**

1. **太虚即气**："太虚无形，气之本体；其聚其散，变化之客形尔"——太虚是气的本然，聚散而不生不灭。
2. **一物两体**："一物两体，气也；一故神，两故化"——气自身含虚实、动静、聚散之对立。
3. **民胞物与**：《西铭》"民吾同胞，物吾与也"——伦理共同体扩展至万物，天人合一经典表达。
4. **德性所知**："见闻之知，乃物交而知，非德性所知；德性所知，不萌于见闻"。
5. **气质之性与变化气质**："形而后有气质之性，善反之则天地之性存焉"；为学在"变化气质"。
> **立论/易错**：张载之气是"虚气相即"的本体论，非粗糙唯物论；民胞物与是境界伦理，非生态口号。心统性情见 Q27。

### Q26 〔北14/16/19/20/23〕 二程的"天理"、理一分殊与"性即理"

**答题要点**

1. **天理**："理者，实也，本也"；理是万物"所以然"与"所当然"的统一——物理与人理（参 [[中国哲学总结]]）。
2. **理一分殊**：程颐《答杨时论西铭书》"《西铭》明理一而分殊"——一理在不同分位有不同表现（亲亲、仁民、爱物各有其分）；朱熹的本体论化见 Q27。
3. **性即理**："性即理也"——性是天理在人身的落实，故性无不善；程颐又以"才"禀于气解释善恶。
4. **识仁与定性（程颢）**："仁者，浑然与物同体"；《定性书》"动亦定，静亦定，无将迎，无内外""廓然而大公，物来而顺应"。
5. **主敬与格物（程颐）**："涵养须用敬，进学则在致知"；敬=主一无适、闲邪存诚（格物见 Q43）。
> **立论/易错**：二程之别是分水岭：程颢重仁体体认，程颐重格物穷理，开出陆王与朱子两线。

### Q27 〔北11/12/14/16/19/20/22/23/24/25；华大25；西电25；华侨11/12/15/16；北26趋势〕 朱熹的理气论、理一分殊与心统性情

**答题要点**

1. **理气**："理也者，形而上之道也，生物之本也；气也者，形而下之器也，生物之具也"；不离不杂，"理先气后"是逻辑在先，"理生气"。
2. **理一分殊**："月映万川"——万物各具一太极，万理同出一源；是程颐"理一而分殊"的本体论化。
3. **心统性情与中和**：性为心之体（理）、情为心之用（气），心统摄二者；中和新说以"未发为性、已发为情"定工夫。
4. **存天理灭人欲与道心人心**："饮食者，天理也；要求美味，人欲也"——辨在是否过其分；道心出于天理、人心出于形气，人心听命于道心。
5. **太极与四德**："太极只是个极好至善的道理"，流行发用为元亨利贞，配仁义礼智。
> **立论/易错**：勿读成"理气二元论""禁欲主义"；格物见 Q43、理气谱系见 Q44。历史地位：理学集大成、四书升格、元明清官学、朱子学东亚化。

### Q28 〔北16；华侨13〕 陆九渊的"心即理"、"发明本心"与"尊德性"

**答题要点**

1. **心即理**："宇宙便是吾心，吾心即是宇宙"；"人皆有是心，心皆具是理，心即理也"——理不在心外。
2. **发明本心**："先立乎其大者"，剥落物欲遮蔽，直指本心；"尽我之心，便与天同"。
3. **简易与尊德性**："易简工夫终久大，支离事业竟浮沉"；以尊德性为先，讥朱子格物为支离（朱陆异同见 Q41）。
> **立论/易错**：象山非不读书，而是反对以读书穷理为成德唯一路径；与朱子同尊天理，分歧在工夫。

### Q29 〔北14/16/17/19/20/22/23/25；华侨13/14/18；西电25〕 王阳明的心学体系：心即理、致良知与四句教

**答题要点**

1. **心即理**："心外无理，心外无事"——理是心的条理，不在事物上另有一个理。
2. **心外无物**：岩中花树——"你未看此花时，此花与汝心同归于寂"；非否认花在，而是意义世界由心开显。
3. **致良知**：良知是"心之本体""天理之昭明灵觉处"，人人具足；致=就良知上实实在在去做。
4. **四句教**："无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物"——天泉证道，王门分歧之端。
5. **万物一体**："大人者，以天地万物为一体者也"——仁者与物同体，晚年境界论。
> **立论/易错**：体系是"心即理—知行合一—致良知—四句教"的圆圈；知行合一详见 Q42，格物正心见 Q43。

### Q30 〔北10/11/12/13；北26趋势〕 王艮的"淮南格物"

**答题要点**

1. **淮南格物**：王艮（泰州人，居淮南）释格物为"絜度"："格，絜度也；物，物有本末之物也"。
2. **身本论**：身与天下国家为一物，身为本、家国天下为末；"身安而天下国家可保"，故"安身立本"。
3. **尊身**："尊身"即尊道，"身与道原是一件"；反对以身为轻的"忘本"。
4. **与朱王之别**：朱子即物穷理、阳明正念头，王艮转向"正己—安身—絜矩"的实践伦理（格物谱系见 Q43）。
> **立论/易错**：淮南格物的核心是"以身为本"的秩序论；泰州学派"满街圣人"的平民化倾向由此出。

## 五、明清之际与近代

### Q31 〔北10/24〕 王夫之的气本论、天下惟器与理势合一

**答题要点**

1. **气本**："太虚者，气之体""气者，理之依也"——理在气中，非气外另有一理。
2. **天下惟器**："无其器则无其道"；道者器之道，道随器变，反对"道先于器"（道器之辩见 Q39）。
3. **理势合一**："势者，事之所因；理者，势之所依"——历史规律（理）与趋势（势）统一。
4. **性日生日成**："日生则日成""未成可成，已成可革"——人性在生命实践中不断生成。
5. **能必副所与知行相资**："能必副其所"——主观须符合客观；"知行相资以为用""行可兼知"（详见 Q42）。
> **立论/易错**：王夫之是古典哲学高峰（气本＋辩证法＋历史哲学），但别只贴"唯物主义"标签；理势论可与黑格尔历史哲学比较。

### Q32 〔北11；华侨15〕 黄宗羲的"盈天地皆心"与理气论

**答题要点**

1. **盈天地皆心**："盈天地皆心也，变化不测，不能不万殊"（《明儒学案·序》）——心为宇宙实存，万殊是心的变化。
2. **理气**："理为气之理，无气则无理"（《孟子师说》）——理不离气，反对理在气先。
3. **心与理一**：心即理，但"心无本体，工夫所至即其本体"——工夫重于悬空的理体。
4. **政治**：《明夷待访录》"天下为主，君为客""为天下之大害者，君而已矣"——民本主义的激进化。
> **立论/易错**："盈天地皆心"是心学立场，非唯心主义标签；与王夫之、顾炎武并称明清之际三大家。

### Q33 〔华大25〕 李贽的"童心说"及其意义

**答题要点**

1. **童心即真心**："童心者，真心也……最初一念之本心也"；人一旦"以闻见道理为心"，童心便失。
2. **反权威**："以孔子之是非为是非，故未尝有是非耳"；六经、《语》《孟》是"道学之口实，假人之渊薮"。
3. **人伦物理即穿衣吃饭**："穿衣吃饭，即是人伦物理"——道德从超越天理拉回日常欲望。
4. **意义**：理学"天理—人欲"结构的内部爆破点，明清个性解放（汤显祖、袁宏道、戴震）先声。
> **立论/易错**：童心说是"真心"的本体论，非"任性"辩护；李贽反的是"以闻见道理为心"的假道学。

### Q34 〔北16/17/18/19/21/23；华大17；华侨15〕 颜元对理学的批判与戴震的"理存于欲"

**答题要点**

1. **颜元习行**："习行"——"犯手实做其事"方是格物；批判静坐读书为"虚文"，主张实学、六艺（格物见 Q43）。
2. **批判理学**：斥宋儒"无事袖手谈心性"；改"正其谊不谋其利"为"正其谊以谋其利，明其道而计其功"。
3. **戴震气化即道**："道，犹行也；气化流行，生生不息，是故谓之道"——道是过程而非超验理体。
4. **理存于欲**："理也者，情之不爽失也"——理是情欲的恰当条理，不与欲对立。
5. **以理杀人/血气心知**："人死于法，犹有怜之者；死于理，其谁怜之"；人性由血气（欲）与心知（知）构成。
> **立论/易错**：颜戴是理学"内部清算"，非全盘反儒；"以理杀人"指理学社会后果，可与权力批判对照但不相等。

### Q35 〔华大25〕 康有为的"托古改制"与三世说

**答题要点**

1. **托古改制**：《新学伪经考》判古文经为刘歆伪造；《孔子改制考》塑孔子为"改制"教主——以今文经学为变法张本。
2. **公羊三世说**：据乱世—升平世—太平世，对应君主专制—君主立宪—民主共和。
3. **意义与限度**：把儒学从"守成"转为"变革"资源；但托古依赖经学权威，随经学解体而失效。
> **立论/易错**：托古改制是"借古人之口说今人之话"的解释学策略，非考据成功；严复讥其"武断"。

### Q36 〔北24〕 严复的进化论与孙中山的"知难行易"

**答题要点**

1. **严复**：《天演论》译介进化论——"物竞天择，适者生存"；以"鼓民力、开民智、新民德"论自强。
2. **孙中山知难行易**：《孙文学说》反"知之非艰，行之惟艰"；以"不知而行""行而后知"论证先行后知。
3. **知行观的政治性**：知难行易是动员论——破"知易行难"的畏难心理，故重"行"。
4. **评价**：近代知行观由道德修养转为实践动员，与王夫之"行可兼知"方向相近而语境不同（见 Q42）。
> **立论/易错**：知难行易是革命实践论而非认识论定论；勿与"实践检验真理"直接等同。

### Q37 〔华侨12/13/16〕 熊十力"体用不二""翕辟成变"与现代新儒家

**答题要点**

1. **体用不二**：《新唯识论》破"摄体归用"与"废用求体"，本体即"恒转"，"即体即用"。
2. **翕辟成变**：恒转有"翕""辟"两势——翕=摄聚成物（形质），辟=运于翕中不为物役（精神），即宇宙创化。
3. **冯友兰新理学**：以"理""气""道体""大全"重建形上学，接程朱而受新实在论影响。
4. **牟宗三**："两层存有论""良知坎陷"（良知自我坎陷开出知性）、道统学统政统三统说。
5. **儒学三期与国学热**：杜维明以先秦—宋明—当代为三期（参 [[中哲读书感想与笔记]]、[[中国哲学十九讲-读书报告]]）；国学热须区分"创造性转化"与"复古主义"。
> **立论/易错**：新儒家是"保卫儒家"的本体论重建，非保守主义政治纲领；牟宗三与康德的"智性直观"之争见本库 [[中哲读书感想与笔记]]。

## 六、跨阶段专题（论述题主战场）

### Q38 〔华大25；华侨09/16〕 中国哲学史上的"天人合一"（含"绝地天通"）

**答题要点**

1. **制度起点·绝地天通**：《国语·楚语下》观射父：颛顼命南正重司天以属神、火正黎司地以属民，断绝"民神杂糅"，通神权归巫史——政教合一与理性化起点。
2. **先秦型**：孟子"尽心知性知天"、《中庸》"天命之谓性"、《易传》"与天地合其德"；荀子"明于天人之分"作批判对照。
3. **汉型**：董仲舒"人副天数""以类合之，天人一也"、灾异谴告——神学目的论形态（见 Q17）。
4. **宋明型**：程朱"天人一理"；程颢"天人本无二，不必言合"；阳明"万物一体之仁"（见 Q26、Q29）。
5. **评价**：积极——内在超越、生态伦理、共同体意识；消极——泛道德主义、"以天压人"；须分"合一（合两为一）"与"本无二（本来一体）"。
> **立论/易错**：须给出"制度—先秦—汉—宋明"型态史，并以荀子、刘禹锡"天人交相胜"说明中国哲学内部也有"分"的传统。

### Q39 〔北17/21/22〕 中国哲学史上的"体用"与道器/形而上形而下

**答题要点**

1. **范畴来源**：体用本于佛教（体=性体，用=作用），经玄学"以无为体"进入中国哲学；程颐"体用一源，显微无间"确立理学形态。
2. **程朱**：理为体、气（象）为用；"至微者理也，至著者象也"，体用非两物而是同一实在两面（参 [[中国哲学总结]]）。
3. **道器**：《易传》"形而上者谓之道，形而下者谓之器"；程朱以道=理、器=气；王夫之"天下惟器"反转道先于器（见 Q31）。
4. **心学体用**：阳明以良知为体、事为用；"心无体，以天地万物感应之是非为体"。
5. **评价**：道器/体用之争实质是"道是否先于器""理是否离气"，正解是"即体即用""道在器中"。
> **立论/易错**：形而上/下不是西方"超自然/自然"之分；体用也不能读成"本质/现象"二元论。

### Q40 〔北15/16/17/18/20/22/25；北26趋势〕 魏晋玄学的有无之辩与名教自然之辨

**答题要点**

1. **先秦源头**：老子"有无相生""天下万物生于有，有生于无"；庄子"有有也者，有无也者"——有无是生成与言说的界限。
2. **王弼贵无**：以无为本、以有为末，无是有的根据（见 Q19）。
3. **裴頠崇有**：《崇有论》"济有者皆有""虚无是有之所谓遗者也""理之所体，所谓有也"——无不能生有，为礼法名教立本体依据。
4. **郭象与佛教**：郭象"自生""无故而自尔"取消第一因（见 Q20）；僧肇"不真故空"以中观改造"无"（见 Q21）；宋明转为"无极而太极""理气"（见 Q44）。
5. **名教自然三型**：王弼"名教出于自然"（仁义发于内，为之犹伪）；嵇康"越名教而任自然"（以"六经为芜秽"）；郭象"名教即自然"（性分各足）。
> **立论/易错**：有无之辩的主线是"本末/体用"，非"存在与非存在"；嵇康非不要秩序，郭象非取消自然。

### Q41 〔北10/13/18/19；西电25；华侨14；华大（朱陆异同年份未详（？））；北26趋势〕 心性论：性即理与心即理、朱陆异同

**答题要点**

1. **心统性情（张载—朱熹）**：性为心之体（理）、情为心之用（气），心统摄二者（见 Q27）。
2. **性即理（程朱）**：性是天理在人身的落实，"灵处只是心，不是性；性只是理"；心是气之灵，具众理而应万事。
3. **心即理（陆王）**："心皆具是理，心即理也""心外无理"——理不在心外，工夫在心上做（见 Q28、Q29）。
4. **朱陆异同**：同尊天理、同去人欲；异在本体（性即理 vs 心即理）、工夫（道问学/格物 vs 尊德性/发明本心）、风格（支离 vs 简易）；鹅湖之会（1175）、无极太极之辩。
5. **尊德性道问学**：朱子以格物补道问学，象山以"先立乎其大"为尊德性——西电 2025 论述即此。
> **立论/易错**：朱陆之争非"唯物 vs 唯心"，而是**成德路径之争**：知识积累能否必然通向道德？

### Q42 〔北12/14/15/17/18/21/23/25；华侨10；西电25〕 中国哲学史上的知行观

**答题要点**

1. **先秦**：孔子"听其言而观其行"；荀子"知之不若行之"；《尚书》"知之非艰，行之惟艰"（伪古文，存疑）。
2. **程朱知先行后**："论先后，知为先；论轻重，行为重"；先知得方能行得，行是知的落实（见 Q27）。
3. **王阳明知行合一**："知是行的主意，行是知的功夫；知是行之始，行是知之成"；"一念发动处便即是行"（见 Q29）。
4. **王夫之与孙中山**："知行相资以为用""行可兼知"（见 Q31）；孙中山反"知之非艰"，以"不知而行""行而后知"为革命张目（见 Q36）。
> **立论/易错**：知行问题不是"先后"排序，而是**道德动机与实践的关系**；"一念发动即是行"最易被误读为取消行动。

### Q43 〔北10/14/16/23/24；华大25；华侨10/13〕 格物论：程颐—朱熹—王阳明—王艮—颜元

**答题要点**

1. **程颐**：格=穷，物=理；"今日格一物，明日格一物"，积习既多然后"豁然贯通"——格物穷理。
2. **朱熹**："即物穷理"——"欲致吾之知，在即物而穷其理"（《大学章句·补格物致知传》）；格物=穷至事物之理。
3. **王阳明**：格=正，物=事——"格者，正也，正其不正以归于正"；格物即正念头，格竹失败是其转折（见 Q29）。
4. **王艮与颜元**：王艮"淮南格物"——格=絜度、以身为本（见 Q30）；颜元格物=习行——"犯手实做其事"（见 Q34）。
> **立论/易错**：格物解释史＝理学转向枢纽：向外穷理（程朱）→向内正心（阳明）→向身/向行（王艮、颜元）。

### Q44 〔北12/13/15/20/22；华侨12；北26趋势〕 理气观：周张二程朱陆王与明代气学

**答题要点**

1. **气本谱系**：张载"太虚即气"（见 Q25）→罗钦顺"通天地亘古今无非一气，理只是气之理"→王廷相"元气之上无物、无道、无理"→王夫之"气者理之依"（见 Q31）；即"气一元论"。
2. **理本论**：二程以理为形上、气为形下；朱熹"不离不杂""理先气后""理生气"（见 Q27）。
3. **心学与方以智**：陆王"心即理"，理气不二于心（见 Q28、Q29）；方以智"质测"（科学）与"通几"（哲学）分途而"质测即藏通几"。
4. **评价**：理气之争＝"理是否离气"；气本论把理还原为气的条理，理本论保留理的规范性。
> **立论/易错**：罗钦顺、王廷相的矛头是朱熹"理生气"，不是"唯物主义"标签可了结；"质测通几"勿等同科学哲学。

### Q45 〔北22/23/24；华侨14/15〕 人性论：孔孟荀董王充与孟荀比较

**答题要点**

1. **孔子**："性相近也，习相远也"——未判善恶，开启"性—习"框架。
2. **孟子**：性善——四端固有、扩而充之，求放心（见 Q3、Q4）。
3. **荀子**：性恶——顺性则争，故化性起伪、隆礼重法（见 Q5）。
4. **孟荀比较及政治影响**：孟子"复性"→仁政、王道、民贵君轻；荀子"化性"→师法礼义、明分使群、隆礼重法；一主性善成德，一主性恶待教，同重教化。
5. **董仲舒与王充**：董"性三品"（圣人之性/斗筲之性/中民之性，待教而成）；王充"性有善有恶"，以气禀厚薄解释（见 Q17、Q18）。
> **立论/易错**：孟荀之争是"复性 vs 化性"路径之争；董、王把人性转为"品级/气禀"问题。

### Q46 〔北19/22；北26趋势〕 名实观与诸子关于"名"的思想

**答题要点**

1. **孔子正名**：名实相符、各守名分，"名不正则言不顺"（见 Q2）。
2. **墨家与名家**："举，拟实也""名，实谓也"（见 Q11、Q13）；公孙龙《名实论》"夫名，实谓也"，正名实而名实当；惠施合同异（见 Q12）。
3. **道法**：老子"名可名，非常名"；庄子"名者，实之宾也"；韩非"循名责实""形名参同"（见 Q7、Q14）。
4. **荀子《正名》**："制名以指实""名无固宜，约之以命"——约定俗成的名实论，中国逻辑学高峰。
> **立论/易错**："名"的争论非语言游戏：正名—辩名—无名—循名，对应礼治—逻辑—语言批判—官僚考核。

### Q47 〔华侨17〕 宋明理学在继承发展传统儒学中表现出的主要特点

**答题要点**

1. **本体论重建**：以理/气/心三系回答"性与天道"，回应佛老"空""无"的挑战（见 Q25、Q27、Q44）。
2. **经典与道统**：四书升格；韩愈道统说被朱熹以"十六字心传"系统化（见 Q23、Q27）。
3. **工夫论与佛老之辨**：主敬、格物、致良知、发明本心（见 Q41—Q43）；借理事、体用、心性之思辨，却在"天理—人欲""伦理—出世"上划界。
4. **伦理政治与官学化**：天理人欲之辨、理一分殊、宗法秩序论；由"接着讲"（韩李—宋初三先生—濂洛关闽）而成官学。
> **立论/易错**：答"特点"须落在"继承什么、发展什么、针对谁"三层，勿写成理学家名单罗列。

### Q48 〔北14/15/16/20/25〕 诸子政治思想比较：儒、墨、道、法

**答题要点**

1. **儒家**：德治礼治——"为政以德"、正名、仁政、民贵君轻；秩序靠教化与差等之爱（见 Q2、Q4）。
2. **墨家**：尚同尚贤兼爱——选贤立天子、一同天下之义、以功利与天志为约束（见 Q11）。
3. **道家**：无为而治——小国寡民、绝圣弃智；秩序靠"自化"而非干预（见 Q7）。
4. **法家**：法术语势——成文赏罚、循名责实、抱法处势；秩序靠制度与权势（见 Q14）。
5. **比较**：人性假设（可教/自利/自然）、秩序来源（德·天志·自然·法）、君民关系（民本/尚同/无为/尊君）；秦亡后"阳儒阴法"成实际结构。
> **立论/易错**：四家不是四个"主义"标签，而是对"周文疲弊"的四种回应；先立比较项再逐项对勘。

### 材料分析与标点翻译题答题法（华侨 878 常考，非 Q）

五步固定动作：**①断出处**（书名·篇名·作者/学派）→**②标点**（据虚词、对文、句式）→**③翻译**（关键词直译）→**④抓概念**（把术语还原为该家学说）→**⑤定位**（思想史坐标与前后关系）。作答三段：出处与文义（1/3）＋概念阐释（1/3）＋思想史定位（1/3）。

常考五段（材料→概念→对应）：朱熹《中庸章句序》"心之虚灵知觉……人心每听命焉"→道心人心、十六字心传（Q27、Q41）；《大学章句·补格物致知传》"所谓致知格物者"→即物穷理、豁然贯通（Q43）；《老子》25 章"有物混成，先天地生"→道之命名（Q7）；《老子》76/78 章"天下莫柔弱于水"→柔弱胜刚强（Q7）；《孟子·告子上》"富岁子弟多赖"→性善、心之所同然（Q3）；《荀子·礼论》"礼起于何也"→欲—求—争—乱、制礼义以分之（Q5）。

## 九、985 精选（中山大学 2003—2026 题库 + 复旦 716）

> 中山大学中哲 431 题（2003—2026，缺 2007）里，高频名解与华南/华侨/北大高度重合（性三品、得意忘象、四端、理一分殊、致良知、独化、太虚即气等，见前面各 Q）。
> 本节只收**前面没展开的新角度**：唯识学、史学转向、经学文本、语言哲学、道教与数术、以及中山特色"材料标点+评析"题的答法。

### N1 〔中大〕阿赖耶识
**答题要点**
1. **定位**：唯识学（法相宗）八识说中的第八识，"藏识"，含藏一切种子（bīja），是生死流转与成佛的依据。
2. **三重义**：能藏（含藏种子）、所藏（受熏成种）、我爱执藏（被第七末那识执为"我"）。
3. **转识成智**：修行转八识成四智（大圆镜智等），故"万法唯识"不是唯心论断言，而是**业力—种子—显现**的结构说明。
4. **中国化**：与《大乘起信论》"一心二门"（见 Q 区）并举，是华严、禅宗心性论的重要理论背景；中山卷常与"一心开二门"同考。
> **易错**：阿赖耶识不是"灵魂"，它是**刹那生灭的相续流**，无固定自性。

### N2 〔中大〕六经皆史
**答题要点**
1. **出处**：章学诚《文史通义·易教上》："六经皆史也。"
2. **含义**：六经不是空言道德的教条，而是**三代政教典制的历史记录**（"六经皆先王之政典"）；"道"寓于"器"、寓于历史事实之中。
3. **方法论**："六经皆史"→ 史学统摄经学，主张"史学所以经世"（经世致用）。
4. **思想史意义**：①消解经学的绝对权威，为清代**史学转向**与近代"以史代经"（章太炎、胡适）铺路；②与戴震"以理杀人"、颜元"习行"共同构成对宋明理学的反拨。
> **立论**：可与王阳明"五经亦史"（《传习录》）对读——阳明以"心"统经，实斋以"史"统经，路径不同而都反对经的教条化。

### N3 〔中大〕以名举实、指非指
**答题要点**
1. **以名举实**（后期墨家《小取》）：名的作用是**举实**（指称对象），"名者，所以举实也"；名实关系是约定与指称的关系。
2. **指非指**（公孙龙《指物论》）："指"（概念/共相）不等于"物指"（具体所指）；"物莫非指，而指非指"——万物都由概念指称，但概念本身不是被指之物。
3. **理论意义**：先秦语言哲学的两条路径——墨家**正名以举实**（指称论）、名家**辨析指与物**（意义与指称之分），可与弗雷格 sense/reference 对照（但不可等同）。
4. **答题落点**：中山常以"白马非马"材料题切入，要求**为公孙龙辩护一句**：其区分的是"马"（形）与"白马"（形+色）的**概念外延**，非否认经验事实。

### N4 〔中大〕慎独（《中庸》《大学》）
**答题要点**
1. **文本**：《中庸》"莫见乎隐，莫显乎微，故君子慎其独也"；《大学》"此谓诚于中，形于外，故君子必慎其独也"。
2. **传统解释**：郑玄、朱熹释为"独处"时亦须谨守；朱熹以"人所不知而己所独知"解，落到**意念初萌**处做工夫。
3. **新解释**（出土文献《五行》《性自命出》后）："独"可释为**心/意**（内在精神），慎独即"**诚意**"——不自欺。
4. **意义**：把道德工夫从外在行为推进到**动机与意念**层面，是宋明"主敬""致良知"的先声。
> **易错**：不要只说"一个人独处要守规矩"，中山卷更看重"**独=意**"这一层。

### N5 〔中大〕《西铭》与"理一分殊"
**答题要点**
1. **《西铭》**（张载《正蒙·乾称》首段，原名《订顽》）："乾称父，坤称母……民吾同胞，物吾与也"。
2. **程颐的评价**：恐人误解为"兼爱"（墨家），故标举"**理一分殊**"——同一气/理贯通，但**亲亲、仁民、爱物各有分位等差**。
3. **朱熹的发展**：以"理一分殊"解《西铭》，把它确立为理学**纲领性文本**（"《西铭》前一段如棋盘，后一段如人下棋"）。
4. **答题落点**：此题实为"**兼爱 vs 差等之爱**"的理学版回答——共同体意识（民胞物与）与差序伦理（分殊）如何并存。

### N6 〔中大〕六家七宗
**答题要点**
1. **所指**：东晋至南朝研究般若学的七个流派（本无、心无、即色、识含、幻化、缘会，加"本无异"为七宗）。
2. **核心分歧**：如何理解"空"——**本无宗**（道安：以无为本）偏于"无"；**心无宗**（支愍度：心不执著外物）偏于主观；**即色宗**（支遁：色即是空，不待析破）。
3. **僧肇的总结**：《不真空论》批评三家"偏而不即"，提出"**不真**故空"——万物缘起故非有，非无而有假名。
4. **意义**：中国佛学由"格义"走向**独立创造**的关键环节，直接通向三论宗与天台宗。

### N7 〔中大〕泰州学派
**答题要点**
1. **定位**：明代阳明后学，王艮（泰州人）开创，代表有王栋、王襞、颜钧、何心隐、罗汝芳、李贽（再传）。
2. **核心主张**："**百姓日用即道**"——道不在经典与静坐，而在日常人伦日用；"满街都是圣人"。
3. **工夫**："**淮南格物**"（见 Q 区格物题）——格物即"安身"，"身"与"道"为一，反对只在心上用功。
4. **影响**：向下开启**平民讲学**与个性解放思潮（李贽童心说），向上则被批评为"**狂禅**"（黄宗羲《明儒学案》的批评）。
> **立论**：泰州学派是理学"下移"的典型——把成圣的资格从士大夫扩展到"愚夫愚妇"。

### N8 〔中大〕五德终始（邹衍）
**答题要点**
1. **内容**：以**五行相胜**（土→木→金→火→水）解释王朝更替，每代有"德"与之相应（"五德转移"）。
2. **文献**：《吕氏春秋·应同》保存其说；《史记·孟子荀卿列传》记邹衍"深观阴阳消息"。
3. **功能**：为**改朝换代**提供宇宙论合法性（"受命"的符应、改正朔、易服色）。
4. **流变**：与董仲舒"天人感应"（见 Q 区）合流，成为汉代政治神学；后被王充《论衡》以"疾虚妄"批判。

### N9 〔中大〕成玄英与"重玄"
**答题要点**
1. **重玄**（道教重玄派）："玄之又玄"——**遣有、遣无、又遣其遣**（双遣），最终"不滞于有无"。
2. **成玄英**：唐初道士，注《道德经》《庄子》（《南华真经疏》），以**佛教中观**解老庄，讲"重玄之道"。
3. **方法**：四句否定（有、无、亦有亦无、非有非无）层层破执，与三论宗"四重二谛"同构。
4. **意义**：道教哲学的形上学化，是**佛道交涉**的典型产物；也影响宋明理学"无极而太极"的思辨结构。

### N10 〔中大〕邵雍的象数学
**答题要点**
1. **《皇极经世》**：以"**元会运世**"推演宇宙历史周期（1 元＝12 会＝129600 年），以数理统摄时间。
2. **先天学**：以"**加一倍法**"（太极→两仪→四象→八卦）推演宇宙生成，先于"后天"（文王）卦序。
3. **"以物观物"**：观物不"以我观物"，而"以物观物"，"**反观**"——认识论上的客观化要求。
4. **评价**：被二程视为"**内圣外王之学**"的另类路径（数术化的宇宙论），朱子既吸收又批评其"硬排"。

### N11 〔中大〕性自命出／《性自命出》
**答题要点**
1. **出土**：郭店楚简《性自命出》（约战国中期），"**性自命出，命自天降**"。
2. **结构**：性—情—道—教：性出于天命，情生于性，道始于情，教所以正情——**情是性的实现方式**。
3. **意义**：证明先秦儒学（思孟一系）已有"**性情论**"雏形，纠正"先秦儒学只讲性不讲情"的误解；为宋明"心统性情"（见 Q 区）提供源头。
4. **与孟子之别**：简文不以"善"规定性，而重"**教/习**"与"**乐**"的化育作用，气质更近"以情显性"。

### N12 〔中大·题型〕材料标点＋评析题怎么答
**答题要点（模板）**
1. **标点**：先通读找"曰/也/矣/乎/者"等句读标记；引文多出自《老子》《孟子》《荀子·礼论》《大学章句》《中庸章句序》《周易略例》等常考文本。
2. **出处与学派**：点明作者、篇章、学派归属（如"朱熹《大学章句》格物补传"）。
3. **核心概念**：抓 1—2 个关键词（如"道心/人心""格物/豁然贯通""崇本息末""四句教"），说明其定义。
4. **思想展开**：该段在体系中的位置（如格物补传是朱子"即物穷理"的总纲）。
5. **评析**：指出内在张力或后世争议（如朱王格物之辨、道心人心是否二元），给出自己的判断——**中山最后一问几乎都要"你的看法"**。
> **高频材料清单**：朱熹《大学章句》格物补传、《中庸章句序》道心人心段、王弼《周易略例·明象》"得意忘象"、王阳明四句教、庄子与惠子濠梁之辩、《老子》25 章"有物混成"、《荀子·礼论》"礼起于何也"、孟子"富岁子弟多赖"章。

### N13 〔复旦〕《新理学》（冯友兰）
**答题要点**
1. **定位**：冯友兰"贞元六书"之首（1939），以**新实在论**（柏拉图式共相）重构程朱理学。
2. **核心**：区分"**真际**"（理世界，逻辑上先于实际）与"**实际**"（现实事物）；"理"是"某物之所以为某物者"。
3. **方法**："**接着讲**"而非"照着讲"——用逻辑分析法讲中国哲学；"正的方法"（逻辑分析）与"负的方法"（直觉体认）互补。
4. **评价**：中国哲学现代化的第一次系统尝试；批评者（如牟宗三、马克思主义学者）指其"理世界"脱离实践、近于新实在论的抽象。

### N14 〔复旦〕庄子论"知"
**答题要点**
1. **"知"的层次**：感官之知（小知）→ 理性分辨（大知）→ **"无知之知"**（"堕肢体，黜聪明"，与道合一）。
2. **齐是非**：是非源于"成心"与立场（见 Q 区齐物论），故"是非之彰也，道之所以亏也"。
3. **"知"的界限**："吾生也有涯，而知也无涯，以有涯随无涯，殆已"（《养生主》）——反对无限求知。
4. **正面义**："**真知**"——"有真人而后有真知"（《大宗师》），知与**生命境界**合一，非命题知识。
> **立论**：庄子不是反智，而是区分**工具性知识**与**体道之知**；可与柏拉图"知识即德性"、海德格尔"真理即无蔽"对照。
