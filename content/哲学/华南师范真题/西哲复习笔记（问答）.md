## 一、古希腊（自然哲学 → 智者 → 苏格拉底 → 柏拉图 → 亚里士多德）

### Q1 〔北10〕 米利都学派：本原与三哲

**答题要点**

1. **转向**：从神话谱系转向"本原（archē）"——万物由之而来、复归其中的始基，以自然本身解释自然。
2. **泰勒斯**："水是本原"；他是"第一位哲学家"（华大 13），因首次以理性—自然而非神意解释万物统一性。
3. **阿那克西曼德**："无定"，由分离生万物，含"补偿"观；**阿那克西美尼**："气"，以稀薄/凝聚释差异，量变生质变之雏形。
4. **意义**：确立一与多、变与不变问题，"本原"成为形而上学核心词。

> **易错**：别用唯物/唯心套评，其意义是解释方式的转变。

### Q2 〔北25〕 毕达哥拉斯的"数本原"

**答题要点**

1. **命题**："数是一切事物的本质"——万物以数为形式，比例即和谐与秩序；数是有限者的原则，给无定者以界限。
2. **理据**：音乐和声（2:1、3:2）、天体运行、几何比例皆可数学化——秩序可被度量，开数学—形而上学传统。
3. **灵魂与修行**：灵魂不朽、轮回、净化，哲学是"对死亡的练习"。
4. **影响**：为柏拉图理念论提供"形式优先"模型（→笛卡尔、莱布尼茨、康德）。

> **易错**：数是关系而非物质元素；洞见是"秩序可数学化"。

### Q3 〔北16〕 赫拉克利特：火、逻各斯与相反者相成

**答题要点**

1. **火本原**：火是"流"的象征——火化生万物、万物复归火（上升/下降之路），又是"尺度"。
2. **流变与逻各斯**："人不能两次踏进同一条河流"（华大 15）；逻各斯是贯穿万物的理性/言说，唯按之行动者清醒。
3. **相反者相成**："战争是万物之父"，弓与琴的张力即和谐；对立统一是运动之源（北 10）。
4. **影响**：黑格尔称"没有一个赫拉克利特的命题我没有纳入我的逻辑学"。

> **易错**：流变与逻各斯不矛盾，他不是相对主义者。

### Q4 〔北11〕 巴门尼德的存在、真理之路与芝诺悖论

**答题要点**

1. **两条路**：真理之路（"存在者存在，不存在者不存在"）与意见之路（凡人"既存在又不存在"、凭感官）。
2. **存在的特征**：不生不灭、不可分、不动、完满（"滚圆的球体"）；"**能被思维者与能存在者是同一的**"（北 23）。
3. **意义**：确立"存在"为哲学对象（本体论开端）；现象/实在二分成为形而上学主线。
4. **芝诺悖论**：飞矢不动、阿基里斯、二分法（华师 21/25）——归谬捍卫"一与不动"，暴露"无限可分/完成无限"难题；亚氏以潜能现实、微积分以极限重解。

> **易错**：to eon 是"使存在者存在的一"，不是存在者集合。

### Q5 〔北10〕 元素论与原子论：恩培多克勒、阿那克萨戈拉、德谟克利特

**答题要点**

1. **恩培多克勒**：四根（水火土气）＋爱/争使之聚散——首次把动力因与质料因分开。
2. **阿那克萨戈拉**：种子"万物在万物中"＋**努斯**安排秩序——目的性理性之始，为柏拉图与亚氏目的论铺路。
3. **德谟克利特**：原子（不可分，形状大小排列不同）＋**虚空**（非存在的合法化）；万物由结合而成（北 10）。
4. **认识与影响**：流射/影像说；感觉是"暗昧认识"、理性是"明亮认识"；伊壁鸠鲁加"偏斜"（Q13）；近代原子论先声。

> **易错**：他分两级认识而非否认感觉；要点＝原子＋虚空＋机械必然＋两级认识。

### Q6 〔北10〕 智者运动与苏格拉底：从"人是尺度"到"美德即知识"

**答题要点**

1. **智者转向**：从 physis 到 nomos（礼法/约定），修辞与伦理成为焦点；相对主义、双重论证与论辩术（华师 10）。
2. **普罗泰戈拉**："**人是万物的尺度**"——感觉主义读法＋人文读法（华师 21/23/24、华大 15）；**高尔吉亚**：无物存在／不可认识／不可表达。
3. **苏格拉底**："**认识你自己**"（华师 10、华大 15），"未经省察的人生不值得过"；**精神助产术**＝反问—归谬逼出定义（华师 16/25）。
4. **美德即知识**：无人自愿作恶，作恶即无知，德性可教（华师 13/22、北 15、华大 16）；困难是**意志薄弱（akrasia）**（解决见 Q12）。

> **立论/易错**："人是尺度"是反神权、重约定的启蒙命题；苏格拉底的知识是实践善知识。

### Q7 〔华师10〕 柏拉图：理念论、洞穴喻、日喻、线喻与回忆说

**答题要点**

1. **理念**：可感物之外的永恒"型相"，是事物的所是与价值标准；具体物"**分有**（methexis）"或摹仿之（华大 18/25）。
2. **洞穴喻**：囚徒（影像/意见）→转身（**periagoge，灵魂转向**）→出洞（见理念）→太阳（善理念）→**返回洞穴**（哲人治国）。
3. **日喻与线喻**：善如太阳，是"存在与认识的共同根据"（华师 23）；线喻四层＝影像—可感物—数学—理念，四级认识（北 22）。
4. **回忆说**："学习即回忆"（《美诺》），由美诺悖论逼出；感觉只作触发（华师 22/23）。

> **立论/易错**：教育不是灌注而是转向；理念论最大困难是第三人难题，见 Q48。

### Q8 〔北17〕 柏拉图：灵魂不朽的证明、灵魂三分与正义

**答题要点**

1. **相反相生**：《斐多》生—死循环，活者由死者来，故灵魂生前生后皆在；辅以回忆说。
2. **单纯性与生命论证**：灵魂非复合故不可分不散灭；灵魂是生命的原则，不能容纳死亡。
3. **灵魂三分**：理性—激情—欲望；健康＝理性统治、激情辅助、欲望服从。
4. **正义**：正义＝各部分"各司其职"，即灵魂内在秩序（《理想国》443c—444a）；正义属"既自身善又结果善"的第二类善，北 17 以古格斯戒指与"不义者灵魂内乱"作答。

> **立论/易错**：正义是灵魂秩序而非外在规范；"由城邦推灵魂"常被批为循环。

### Q9 〔北16〕 亚里士多德：批判理念论、四因说、形式质料、潜能现实

**答题要点**

1. **批判**：①**分离**——理念与事物分离，不能解释运动生成；②"分有"是"空洞的诗喻"（《形而上学》A9）；③**第三人**无穷倒退。
2. **四因**：质料、形式、动力、目的；后三常合一为形式，四因即"为什么"的四种答法（华大 14 要求举例）。
3. **形式与质料**：形式是"使某物成为某物"的本质（＝定义），与质料不可分离；形式即现实。
4. **潜能与现实**：生成是"潜能→现实"的实现，解决了柏拉图无法解释的运动（"人＝理性动物"）；成目的论—机械论之争的坐标（→Q24）。

> **立论/易错**：亚氏不是抛弃理念而是**把形式内在化**。

### Q10 〔北22〕 亚里士多德：实体、第一哲学、目的论、运动三本原

**答题要点**

1. **实体**：第一实体＝个别事物，第二实体＝种属；"**既不述说主体、又不存在于主体之中**"（《范畴篇》）；Z 卷转以形式/本质为首要实体（华师 24）。
2. **第一哲学**：研究"作为存在的存在"及首要原因；"**存在不是一个种**"（《形而上学》B3）——存在有多种意义（北 23）。
3. **目的论与运动三本原**：自然物有"为了什么"（北 17）；运动三本原＝质料、形式、缺乏（北 21）。
4. **不动的推动者**：永恒运动需纯形式纯现实的第一推动者——"思想思想自身"，被阿奎那接续为上帝（Q18）。

> **易错**："实体不可能是质料"（北 24）——质料只是潜能、无规定；"存在不是种"须能复述。

### Q11 〔北11〕 亚里士多德：灵魂论与感觉理论

**答题要点**

1. **灵魂是形式**：灵魂是"自然有机体的第一现实性"，身体是质料、灵魂是形式（《论灵魂》B1—B2）。
2. **水手与船**：亚氏批评"灵魂如水手在船上"的分离论（B1, 413a8-9），二者是形式—质料的不可分整体（北 25）。
3. **能力三级**：营养（植物）—感觉（动物）—理性（人）；"人是理性动物"。
4. **感觉与理性**：感觉接受可感**形式**而不接受质料（"印章在蜡上"）；错误源于判断；被动理智与**主动理智**（不死永恒）之分是中世纪争论焦点（北 11）。

> **易错**：亚氏灵魂论是生物学形式论，非笛卡尔式二元论。

### Q12 〔北19〕 亚里士多德：中道、意志薄弱（akrasia）与德性生活

**答题要点**

1. **最高善**：幸福（eudaimonia）＝"灵魂合乎德性的活动"（《尼各马可伦理学》I7，华大 17）。
2. **中道**：德性在过度与不足之间、由实践智慧（phronēsis）在情境中确定（II6），非算术平均。
3. **akrasia**：明知善而不行——非真知而是被欲望遮蔽的感觉知识，故仍有责任（VII）。
4. **与苏柏之别**：苏格拉底"无人自愿作恶"取消 akrasia；亚氏区分不自愿/自愿/选择，把责任归于选择（北 23）；沉思（X7—8）是最高幸福。

> **立论/易错**：中道是"情境中的恰当"而非折中；德性生活落"活动—实践智慧—沉思"。

## 二、希腊化（伊壁鸠鲁、斯多亚、怀疑派、犬儒）

### Q13 〔华师13〕 伊壁鸠鲁：原子论与快乐主义

**答题要点**

1. **原子与虚空**：承德谟克利特，加"**偏斜**（clinamen）"——原子下落有微小偏离，为自由与偶然留余地。
2. **感觉主义**：感觉是真理标准（"一切感觉皆真"），错误在判断。
3. **快乐主义**：快乐＝身体无痛苦（aponia）＋灵魂无纷扰（ataraxia）；"快乐是幸福生活的起点与终点"——故"快乐就是幸福"（华师 21）。
4. **分类与神**：快乐分自然且必要/自然不必要/非自然非必要，故非纵欲而节制审慎；神不干预人事，"死亡与我们无关"。

> **易错**：其快乐是消极的无痛无扰，不是享乐主义。

### Q14 〔华师10〕 斯多亚：命运、自由、幸福与"美德即知识"

**答题要点**

1. **宇宙论**：逻各斯（理性/火）贯穿宇宙；命运＝因果必然的链条，即宇宙理性。
2. **顺应自然**：德性即"依自然而生活"；外物是"无关紧要者"（adiaphora）；幸福＝德性生活本身（华师 25）。
3. **命运与自由**："愿意的人被命运领着走，不愿意的被拖着走"；自由＝认识并意愿必然，是**内在自由**（北 22、华师 23）。
4. **情感与影响**：激情是错误判断，故德性＝apatheia（不动心）；四主德统一于知识——"**美德即知识**"（华师 25）；影响自然法、世界公民、康德义务论（华师 10）。

> **易错**：其命运不是宿命论而是宇宙理性；自由是内在自由（Q55）。

### Q15 〔华师24〕 怀疑派与犬儒：悬搁判断与自足

**答题要点**

1. **皮浪主义**：事物不可判定；对一切"**悬搁判断**（epochē）"→得不动心（ataraxia），随境遇而生活（华师 24）。
2. **十式与学园派**：现象差异、视角、感官相对等构成"同等力量的对立"；学园派主张"只有信念"、或然性。
3. **犬儒**："**自足**（autarkeia）""依自然反礼法""无所需即近神"，以行为实践哲学（北 10）。
4. **意义**：怀疑派→蒙田、休谟、现代知识论；犬儒→斯多亚的自足与反文明批判。

> **易错**：犬儒是伦理严格主义，不是玩世不恭。

## 三、教父与中世纪（奥古斯丁、波爱修/波菲利问题、安瑟尔谟、阿奎那、司各脱、奥卡姆、共相之争）

> 本节 Q16—Q19。**安瑟尔谟本体论证明见 Q49，波菲利问题与共相之争见 Q50**；普罗提诺太一与流溢见 Q48。

### Q16 〔北17〕 奥古斯丁：光照说、信仰与理性、时间学说

**答题要点**

1. **信仰与理性**："**信仰寻求理解**"（credo ut intelligam）——先信后懂，理性仍有独立运思空间。
2. **光照说**：永恒真理不在变动的感觉与人心，只能来自"高于理性"的上帝之光——日喻的基督教版（北 17、华师 13/16）。
3. **认识层级**：感觉→内在感觉→理性→光照；记忆整理材料，概念须受光照规则方能成为知识（北 22）。
4. **时间**：时间是"**心灵的延展**（distentio animi）"——过去＝记忆、现在＝直观、将来＝期待；上帝在时间之外（《忏悔录》卷十一）。

> **易错**：光照是认识的可能性条件而非神谕；时间主观化启胡塞尔、海德格尔。

### Q17 〔北24〕 奥古斯丁：恶的来源、原罪、自由意志、恩典与双城

**答题要点**

1. **恶的来源**：恶非实体而是"**善的缺乏**（privatio boni）"、非存在——受普罗提诺影响，反驳摩尼教二元论（北 25）。
2. **三类恶**：物理的恶、认识的恶、伦理的恶（意志偏离善）；个体恶衬托整体善。
3. **自由意志与原罪**：始祖滥用自由意志堕落，人性被原罪损伤——"不是不能为善，而是不愿"（华师 24）。
4. **恩典与双城**：得救靠恩典（与佩拉纠之争），"愿意向善"亦为恩赐→预定论；上帝之城（爱上帝）与地上之城（爱自己）终末分离。

> **立论/易错**：恶—自由—恩典须连贯：恶出于自由，但自由已损伤，故须恩典。

### Q18 〔北10〕 阿奎那：五路证明、本质与存在、灵魂、对理念论的批评

**答题要点**

1. **五路（后验）**：运动→不动的推动者；因果→第一因；偶然/必然→必然存在者；完满等级→最完满者；目的→设计者（《神学大全》I q2 a3）；共法＝"**不可无穷倒退**"（华师 22、北 22、华大 23/25）。
2. **不接受安瑟尔谟**：上帝存在对人非自明命题，"从概念到存在"的先天证明无效，只能从受造物回溯（北 20；详辨见 Q49）。
3. **本质与存在**：受造物中"是什么"与"是否"**实在区分**；唯上帝本质即存在——故上帝必然，其他偶然（北 21、华师 23）。
4. **灵魂与共相**：灵魂是身体的形式（非柏拉图式囚禁），理性灵魂非物质故不死（华师 12）；理念是上帝心中的原型，共相"在事物之前—之中—之后"，拒绝以分有解释可感物（北 20）。

> **易错**："哲学是神学的婢女"须与"**恩典不摧毁自然，而是成全自然**"并说。

### Q19 〔北17〕 司各脱的"此性"与奥卡姆的剃刀

**答题要点**

1. **此性（haecceitas）**：使个别物成为"**这一个**"的终极形式，不可再用种属表述（北 22）。
2. **司各脱的意志主义**：意志高于理智，意志自由且无动力因；"一切学科都不证明其对象的存在"。
3. **奥卡姆剃刀**："**如无必要，勿增实体**"——解释力相等时不增设实体（北 17、华师 25、西电 25、华大 17/25）。
4. **唯名论与后果**：共相只是心灵的概念/符号，个别才是唯一实在（"指代"理论）；后果是经验论与个体主义、唯意志论、理性神学的裂隙。

> **易错**：剃刀是"同等解释力下不增设实体"的方法论原则。

## 四、近代唯理论（笛卡尔、斯宾诺莎、莱布尼茨、马勒布朗士、帕斯卡）

### Q20 〔华师23〕 笛卡尔：普遍怀疑、我思故我在、错误的根源

**答题要点**

1. **方法论怀疑**：感官可欺、梦境不可辨、恶魔假设——凡可疑者悬置；怀疑是"一次性清场"的方法（北 22、西电 25）。
2. **我思故我在**：怀疑本身不可怀疑——"我在思维"是当下直观的确定性（《沉思集》II，华师 23/24/25、华大 11）。
3. **不是三段论**：它是**直观**而非"凡思者在→我在"的推理，否则须预设大前提（北 24）。
4. **错误的根源**：错误不在知性而在**意志越界**——对不清楚明白者下判断（《沉思集》IV，北 21）；"清楚明白"是真理标志（北 10）。

> **立论/易错**："近代哲学之父"（华大 17）＝以我思为起点、以清楚明白为标志、以机械论统一自然。

### Q21 〔北19〕 笛卡尔：上帝存在的证明、天赋观念、灵魂不朽

**答题要点**

1. **第三沉思两个证明**：①"无限完满者"观念的原因实在性不能小于该观念；②我不完满却怀有完满观念，故非我所造（北 19/23）。
2. **第五沉思与循环**：完满者必含存在（本体论证明，见 Q49）；"笛卡尔循环"＝以清楚明白证上帝、又以上帝保证清楚明白。
3. **天赋观念**：上帝、自我、数学公理"与生俱来"（非现成而是倾向）；三类观念：天赋/外来/自造（华师 16/21/23/25）。
4. **灵魂不朽**：灵魂是单纯不可分实体（无部分故不可解体）→自然不朽，最终保证仍需恩典（北 23）；实体＝不需他物即存在者（Q52）。

> **易错**：第三沉思两证明是"后天"的，第五沉思才是"本体论"。

### Q22 〔北11〕 斯宾诺莎：实体、属性、样态、"规定即否定"与自由

**答题要点**

1. **实体＝神＝自然**（deus sive natura）：实体在自身内并通过自身而被认识，是**自因**；唯一、无限、永恒、不可分。
2. **唯一性与规定即否定**：两实体必相互限制；同一属性不能分属两实体——故只有一实体（北 24）；一切限定都是对无限实体的否定，故上帝无意志目的（西电 24）。
3. **属性与样态**：属性是理智所见的实体本质（人知思维与广延）；样态是实体的分殊（个别事物、心灵状态）。
4. **自然与自由**：能动的自然（natura naturans）与被动的自然（natura naturata）（北 15）；自由＝认识必然、依理性生活（"不哭不笑，而是理解"）；"事物次序"即观念次序＝事物次序（北 11，Q51）。

> **易错**：斯宾诺莎非无神论亦非唯物论，是**中性一元论**。

### Q23 〔北10〕 莱布尼茨：单子、前定和谐、两种真理、逻辑方法的改进

**答题要点**

1. **单子**：单纯、无部分、不可分的精神性"形而上学的点"；"**单子没有窗户**"——变化由内在本性（力）展开；有知觉清晰度之别。
2. **前定和谐**：上帝预定各单子状态彼此一致——身心一致与万物秩序皆"预定的和谐"，替代偶因论（华师 10/12/13/16）。
3. **两种真理**：推理的真理依**矛盾律**（必然）；事实的真理依**充足理由律**（偶然）（华师 23/25）。
4. **逻辑方法与批白板**：明确提出充足理由律；"**普遍字符＋推理演算**"欲把推理化归为计算——数理逻辑先声（华大 25）；观念是"倾向、禀赋、潜能"（大理石纹理），经验只使之变清晰（Q26）。

> **易错**：与斯宾诺莎对立＝多 vs 一、目的/自由 vs 严格必然。

## 五、近代经验论（培根、霍布斯、洛克、贝克莱、休谟、里德）

### Q24 〔华师16〕 培根：四假相说与《新工具》对《工具篇》的科学方法革命

**答题要点**

1. **四假相（假象说）**：种族（人性以人为尺度）、洞穴（个人教养）、市场（语言误用）、剧场（哲学体系：诡辩派/经验派/经院派）（华师 16、北 16、华大 09）。
2. **《新工具》vs《工具篇》**：亚氏《工具篇》是**三段论演绎**（从必然前提出发作证明）；培根《新工具》是**归纳法**（从经验逐级上升到公理），辅以"三表法"。
3. **知识就是力量**："服从自然才能支配自然"；蚂蚁—蜘蛛—蜜蜂之喻说明归纳须与理性结合。
4. **与亚氏分歧**：目的论 vs 机械论、**证明 vs 发现**、静观 vs 效用；但培根未弃演绎（华大 25 采分点）。

> **立论/易错**：比较题要讲"方法的目的与结构"之别，不要简单褒贬。

### Q25 〔华师10〕 霍布斯：哲学方法＝加减、自然状态、社会契约与利维坦

**答题要点**

1. **方法＝加减**：一切推理都是"计算"——分析（分解为简单观念）与综合（组合）（北 21）。
2. **自然状态**："**人对人像狼**"——人性自利、欲望无穷、能力相近，故"一切人反对一切人的战争"，无正义无财产无法律（华师 22）。
3. **自然法、契约与利维坦**：自我保全是最基本自然权利；自然法要求寻求和平、放弃部分权利（北 10/11）；众人让渡权利给主权者（"人造的人"），主权不可分割不可反抗（华师 10）。
4. **与洛克之别**：霍布斯让渡几乎全部权利、主权绝对；洛克只让渡部分、保留反抗权与分权（Q26）。

> **易错**：其问题意识是内战恐惧与秩序根据；自然状态是反"人是政治动物"的近代假设。

### Q26 〔北10〕 洛克：白板、批判天赋观念、第一性质与第二性质、简单观念

**答题要点**

1. **白板**：心灵本无观念，知识来自经验（感觉＋反省）；"凡在理智中的，无不先在感觉中"（华师 16）。
2. **批判天赋观念**：若天赋应人人共知（婴儿白痴不知）；实践原则无普遍同意；所谓天赋实为后天习得而遗忘来源（华师 23/25）。
3. **简单观念与复杂观念**：简单观念被动接受、不可再分（北 15）；复杂观念由心灵组合比较抽象而成；"实体"只是被假设的支撑者。
4. **两性质与政治**：第一性质（广延、形状、运动、数目）为物体固有；第二性质（色声香味）是"借第一性质在我们心中产生观念的能力"（北 10/16/22、华师 21）；政治上自然权利不可让渡、政府是信托（北 22）。

> **立论/易错**：第二性质学说造成"科学实在论与常识知觉的分裂"，贝克莱由此出发（Q27）。

### Q27 〔北15〕 贝克莱："存在就是被感知"及其论证与缺陷

**答题要点**

1. **命题**："**存在就是被感知**"（esse est percipi）——可感物的存在即被感知或被感知的可能性（华师 22、北 21）。
2. **论证三步**：第二性质主观（洛克已认）；第一性质与第二性质不可分（无法设想无色的广延）→第一性质亦主观；"物质实体"是抽象虚构（北 15/16）。
3. **观念集合与上帝**：物是观念的集合（华师 23）；未感知之物仍存在，因**上帝永恒感知**——"观念客观化"（华师 10）。
4. **缺陷**（北 25）：说不清感知者不在场时的存在；取消因果与共时性；靠上帝补救反成独断、易滑向唯我论。

> **易错**：锋芒是反"物质实体独断论"而非否认常识。

### Q28 〔北16〕 休谟：因果关系、印象与观念、怀疑论与宗教批判

**答题要点**

1. **印象与观念**：一切观念来自印象，观念是印象的摹本（"印象在先"）；简单观念必须有印象（华大 14）。
2. **因果推理**：从未感知"必然联系"，只感知接近、接续、**恒常会合**；必然性是心灵的习惯性联想——"习惯是人生的伟大指南"（北 16）。
3. **归纳与或然**：从"过去如此"推"将来如此"无理性根据；因果知识只是或然知识（华师 23、北 23）。
4. **怀疑论与后续**：温和怀疑论；《自然宗教对话录》驳设计论证、《论奇迹》；"是—应当"问题（华师 25）；后续康德以先天范畴回应（Q53）、里德以常识实在论批"观念体系"（速查表）。

> **立论/易错**：休谟不是否定因果，而是把必然性从世界挪到心灵。

## 六、法国启蒙与德国古典（伏尔泰、孟德斯鸠、卢梭、法国唯物主义、康德、费希特、谢林、黑格尔）

### Q29 〔华师10〕 伏尔泰的自由学说与孟德斯鸠的三权分立

**答题要点**

1. **伏尔泰的底子**：洛克与牛顿的普及者；自然神论（上帝是"钟表匠"），猛烈批判教会（"消灭败类"）。
2. **自由学说**：自由是"**依据自己的意志行动的能力**"，即能做想做的事；反对无动机的绝对自由，也反对严格决定论取消责任（华师 10/12）。
3. **孟德斯鸠政体论**：《论法的精神》三型——共和（德性）、君主（荣誉）、专制（恐惧）；"法的精神"＝政体、地理、气候、风俗的总关系。
4. **三权分立与评价**：立法/行政/司法相互牵制，"以权力制约权力"，影响美国宪法；伏尔泰的自由是消极自由雏形，孟德斯鸠开制度自由主义。

> **易错**：伏尔泰既非绝对自由论者亦非决定论者；地理环境论非地理决定论。

### Q30 〔华师25〕 卢梭：平等、公意、社会契约；18 世纪法国唯物主义

**答题要点**

1. **自然状态与不平等**：自然人自由平等；**私有制**（"谁第一个圈地并说这是我的"）产生财产、权势、名望的不平等（华师 25）。
2. **社会契约与公意**：成员把权利让渡给共同体；**公意**（volonté générale）是共同体的普遍意志，不等于"众意"之和（华师 16、北 11）。
3. **自由＝服从自己参与制定的法律**："人生而自由，却无往不在枷锁之中"——积极自由之源，也是"以公意压个体"的批评焦点。
4. **法国唯物主义**：拉美特利《人是机器》（北 10）；狄德罗——物质有感受性；**爱尔维修**——"**人是环境的产物**"、教育万能（华大 16）；霍尔巴赫——机械决定论。

> **易错**：公意≠全体一致、≠多数票；卢梭的平等是权利平等而非财产平等。

### Q31 〔北20〕 康德：哥白尼式革命、先天综合判断、先验幻相与物自体

**答题要点**

1. **哥白尼革命**：不是认识符合对象，而是"**对象符合认识的形式**"——"**人为自然立法**"（华大 16）；知识＝形式＋内容（华师 16/22、西电 25）。
2. **先天综合判断如何可能**：数学（时空为**直观形式**）、自然科学（**范畴**为知性形式）、形而上学（理性越界生**先验幻相**）（北 20）。
3. **范畴与统觉**：12 范畴＋"**我思必须能够伴随我的一切表象**"是经验统一性的最高条件（华师 23/25）。
4. **幻相、二律背反、物自体**：四组二律背反（时空、单纯、自由、上帝）暴露理性界限（北 16/21）；物自体"不可知但可思"，限制知识并为实践留地；"**思维无内容是空的，直观无概念是盲的**"（华师 13/24；Q54）。

> **立论/易错**："先天"≠"天生"；康德是先验唯心论者，不是贝克莱式唯心论者。

### Q32 〔华师16〕 康德：实践哲学、绝对命令、根本恶与自由

**答题要点**

1. **绝对命令**：①普遍化公式"只按你同时愿意它成为普遍法则的准则行动"②人是目的公式"把人当作目的，绝不只是手段"（华师 16/24）。
2. **自律与义务**：道德律由理性自身立法；定言命令 vs 假言命令；义务与偏好之别——实践哲学核心（华大 17）。
3. **自由与道德**：自由是道德律的"存在根据"，道德律是自由的"认识根据"；"**你应当，故你能**"（北 24/25）。
4. **根本恶与悬设**：趋恶的倾向使准则颠倒——恶是**准则的颠倒**而非感性本身（北 25）；悬设自由、灵魂不朽、上帝；"**我不得不悬置知识，以便为信仰留地盘**"。

> **立论/易错**：康德不是无情的形式主义；根本恶是自由选择的责任（Q55）。

### Q33 〔华师10〕 康德：判断力批判——美、崇高、艺术；席勒"美在自由"

**答题要点**

1. **判断力的位置**：沟通自然（知性）与自由（理性）——"自然的合目的性"；反思判断力是体系的桥梁。
2. **美的分析**：无利害的愉悦、无概念的普遍性、无目的的合目的性、必然的愉悦；"美是道德的象征"；审美共通感。
3. **崇高**：想象力不及理性整体要求，痛感转快感；崇高不在对象而在心灵能力的关系。
4. **艺术与席勒**：艺术是"自由的游戏"，天才是为艺术立法；**席勒"美在自由"**（华大 16）——美是感性冲动与形式冲动的统一、审美是游戏冲动，人以美走向自由。

> **易错**：美是"主观的普遍性"而非主观任意。

### Q34 〔北24〕 费希特的知识学与谢林的同一哲学

**答题要点**

1. **前两原理**："**自我设定自身**"（绝对无条件的行动而非事实）＋"自我设定非我"（非我是自我活动的产物与限制）（北 11、华师 10/12）。
2. **第三原则**：自我与非我在绝对自我中"相互限制"，实践理性由此展开；问题是非我既被设定又被限制，陷入循环（北 24）。
3. **谢林同一哲学**：绝对者＝主体与客体的"**无差别同一**"；自然哲学与**先验哲学**两条互补路径；理智直观把握绝对（华师 13/25、北 10）。
4. **关系**：费希特的正—反—合是辩证法前身；黑格尔批谢林"绝对"是"黑夜中一切牛皆黑"（Q35）。

> **易错**：费希特的"自我"是绝对主体性而非个人心理自我。

### Q35 〔北17〕 黑格尔：实体即主体、绝对精神、否定辩证法、"真理是过程"

**答题要点**

1. **实体即主体**："不仅把真实的东西表述为**实体**，而且表述为**主体**"；实体是自我展开自我认识的过程（华师 24；华大 25 名解《精神现象学》）。
2. **绝对精神与异化**：逻辑学→自然哲学（理念**外化/异化**）→精神哲学（艺术、宗教、哲学）（华师 13、西电 25；华大 18）。
3. **否定辩证法与真实无限**："**扬弃**"＝否定＋保存＋提升；"真实无限"非有限者的无限延长（恶无限），而是有限在自身中扬弃自身、圆圈式返回（北 25、华师 22）。
4. **真理是过程与批康德**："真理是全体"、"真理是一个过程"（华师 23）；批康德：物自体空洞、道德律形式主义（须加入伦理实体）、知性不能把握真理（华师 25）。

> **立论/易错**："实体即主体"不是"实体＝人"；黑格尔的异化≠马克思的异化劳动。

### Q36 〔北20〕 黑格尔：自我意识与主奴辩证法

**答题要点**

1. **自我意识**：欲望—生命—**承认**的运动；自我意识只有通过另一个自我意识才成为自我意识——"我就是我们，我们就是我"（北 21）。
2. **主奴辩证法**：为承认而斗争——一方以生命冒险成为**主人**、一方畏死成为**奴隶**；主人依赖奴隶的承认。
3. **劳动的意义**：劳动是"被欲望延缓的消灭"——奴隶在塑造物中看到自己的形式而获得独立性，主奴由此辩证颠倒（北 20）。
4. **意义与限度**：马克思、科耶夫、萨特、霍耐特的共同源头；限度是带目的论色彩的历史模型。

> **立论/易错**：主奴胜负是"辩证的颠倒"而非道德褒贬。

## 七、现代西方哲学（叔本华、尼采、胡塞尔、海德格尔、萨特、弗雷格、罗素、维特根斯坦、赖尔、普特南、克里普克、詹姆斯）

### Q37 〔华师13〕 叔本华的生命意志与尼采的权力意志

**答题要点**

1. **叔本华**：世界＝表象＋意志；意志是盲目的**生存意志**，欲求—满足—无聊的循环，痛苦是本质（华师 16/21/24）；解脱靠审美直观、禁欲、否定意志。
2. **尼采的权力意志**：意志的本质是求**增长与超越**（Wille zur Macht）——对叔本华的翻转；"上帝死了"→重估一切价值、主人/奴隶道德、超人、永恒轮回（华师 13/23/24）。
3. **批判理性主义**：理性/逻辑是"保存生命的工具"，概念化抹平差异（华师 24 简答）；《悲剧的诞生》日神/酒神；视角主义。
4. **发展关系**（华师 25）：保留"意志"为实在，去掉"否定意志"的结论——以"肯定生命"取代禁欲。

> **立论/易错**：尼采不是虚无主义者（虚无是他诊断的病症）；权力意志是力的自我超越。

### Q38 〔北25〕 胡塞尔：现象学的"现象"、意向性与现象学还原

**答题要点**

1. **现象学的"现象"**：不是现象主义的感觉材料，而是意识活动中直接给予的**本质**——"回到事情本身"（北 25）。
2. **意向性**：一切意识都是"关于某物的意识"（noesis—noema）；对象是"意向相关项"而非心理内容（北 26）。
3. **现象学还原**：悬搁自然态度→本质还原（自由变更求本质）→先验还原（回到先验自我与意义构成）。
4. **是否笛卡尔主义**（北 25）：是（以我思为不可怀疑起点、求明见性）；不是（先验自我非实体，世界作为意向相关项被保留）。

> **易错**：还原不是怀疑世界存在，而是悬置对存在的素朴信念。

### Q39 〔综21〕 海德格尔：此在与在世之在

**答题要点**

1. **存在问题**：存在（Sein）不是存在者，"存在论差异"——重提被遗忘的存在问题。
2. **此在（Dasein）**：唯一能追问存在的存在者，其存在方式是"生存"——"此在的本质在于它的存在"。
3. **在世之在**：此在总是已在世界中——不是主客二分，而是"操心（Sorge）"的统一结构；用具与现成之别（综 21）。
4. **本真与非本真**：被"常人"支配的沉沦（闲谈/好奇/两可）；畏逼出本真，"向死存在"使生存整体化。

> **易错**："在世之在"是存在论结构，不是"人在世界中"的空间关系。

### Q40 〔北25〕 萨特：自我意识、自欺与"存在先于本质"

**答题要点**

1. **反思前的我思**：意识总是对某物的意识，且是**反思前的**——自我意识不是"我"作为对象（北 25）。
2. **自在与自为**：自在"是其所是"（物）；自为"是其所不是、不是其所是"的虚无化——自由即虚无。
3. **自欺（mauvaise foi）**：人对自己隐瞒自己的自由（侍者把自己当角色）；自欺可能因意识"不是其所是"（综 21）。
4. **他者与自由**：他者注视把我对象化（羞耻），"他人即地狱"；人被"判定为自由"；**存在先于本质**（华大 15）——人先存在，再由选择造就本质。

> **易错**：萨特的自由是意识结构而非"想做什么都行"；自欺≠说谎。

### Q41 〔北23〕 弗雷格：涵义与指称、同一陈述、专名交流

**答题要点**

1. **涵义与指称（Sinn/Bedeutung）**："晨星"与"昏星"指称同一对象（金星）而涵义不同。
2. **同一陈述**（北 23）：若 a=b 只表对象相同，则"晨星=晨星"与"晨星=昏星"无认知差别；差异只能来自**涵义**，故 a=b 有认知价值。
3. **专名交流**（北 25）：不同人对同一专名的涵义把握可不同；交流只需指称相同、涵义足够重合。
4. **逻辑与影响**：语句指称是真值、涵义是思想；概念文字奠定现代逻辑；影响罗素、维特根斯坦、克里普克（Q46）。

> **易错**：涵义是客观的"思想"，不是心理意象。

### Q42 〔北25〕 罗素：摹状词理论、描述的知识与亲知的知识

**答题要点**

1. **摹状词理论**："当今法国国王是秃头"分析为 ∃x(Kx∧∀y(Ky→y=x)∧Bx)——"存在"是量词而非谓词。
2. **描述的知识与亲知的知识**（北 25）：亲知＝直接感知/记忆/内省；描述＝通过摹状词间接知道。
3. **排中律**：经分析后该命题与其否定不再同为假，排中律成立，同时解决"非存在对象"难题（综 21）。
4. **逻辑原子主义与批评**：世界由原子事实构成；类型论解罗素悖论；斯特劳森（预设）、唐纳兰（指称用法）批评。

> **易错**：摹状词理论不是否认存在，而是重析存在命题的语法形式。

### Q43 〔综21〕 维特根斯坦：语言游戏与家族相似

**答题要点**

1. **前期**：《逻辑哲学论》——语言与世界同构（图像论）；"凡不可说的，应当沉默"。
2. **后期**：语言游戏、**意义即用法**（"不要想，而要看"）、生活形式。
3. **家族相似**：游戏无共同本质，只有交错的相似网络——反本质主义；对苏格拉底/《泰阿泰德》式"定义"追问的批评（综 21、华大 10）。
4. **规则遵循与影响**：规则不能私人地遵循；影响日常语言哲学、心智哲学与社会科学。

> **易错**：家族相似不是"没有共同点"，而是"没有单一本质"。

### Q44 〔北25〕 赖尔：范畴谬误与对笛卡尔二元论的批判

**答题要点**

1. **范畴谬误**：把属于一个逻辑范畴的东西当作另一范畴——如把"心灵"当成与身体并列的"东西"。
2. **机器中的幽灵**：笛卡尔的身心二元是范畴错误（the Ghost in the Machine）。
3. **知道如何/知道那个**：心灵活动不是隐秘内在事件，而是能力与倾向的展现；心理词项是 disposition 描述。
4. **是否奏效**（北 25）：有力——揭露"实体化心灵"的语法误导；不足——难说明感受质、第一人称权威与意识现象性。

> **易错**：赖尔不是否认心灵，而是否认"心灵是另一种实体"。

### Q45 〔北?〕 普特南：钵中之脑与语义外在论

**答题要点**

1. **钵中之脑**：大脑置于营养液中、由电极刺激制造完整经验——我们如何知道自己不是钵中之脑？
2. **语义外在论**：指称依赖外在环境（"水"指称 H₂O 依赖环境；孪生地球的"水"＝XYZ）——意义不在头脑中。
3. **自我反驳**：若我们是钵中之脑，则"钵""脑"不指称真实对象，故该假设不能为我们所一致地陈述。
4. **内部实在论**：真理＝理想化的理性可接受性；批评：模态论证、可设想性反驳。

> **易错**：结论不是"证明我们不是钵中之脑"，而是该假设自我反驳。

### Q46 〔北26〕 克里普克：严格指示词、命名与必然性

**答题要点**

1. **严格指示词**：在一切可能世界指称同一对象的词项；专名与自然种类词是，摹状词不是。
2. **因果历史链条**：专名通过"初始命名＋因果链条"获得指称，而非靠涵义。
3. **必然/偶然与先天/后天**：存在"后天必然"（水是 H₂O）与"先天偶然"（米原器是一米长）——打破"先天＝必然"。
4. **批心脑同一论**（北 26）：若"疼痛"是严格指示词，则"疼痛＝C 纤维激发"若是同一即必然；但可设想疼痛而无 C 纤维激发，故该同一论不成立。

> **易错**：克里普克允许科学发现后天必然同一，反对的是"同一＝偶然"。

### Q47 〔北25〕 詹姆斯与美国实用主义的真理观

**答题要点**

1. **皮尔士的原则**：概念的意义在于可设想的实践效果；信念是行动的习惯。
2. **詹姆斯的真理观**（北 25）：真观念是"能吸收、验证、确认的观念"；真理是观念的**可证实性/兑现价值**（cash value），在实践中被"造出"。
3. **真理的成长**：真理历史累积、多元生成；彻底经验主义（纯粹经验之流）；"信仰意志"。
4. **杜威与批评**：工具主义（思想是解决问题的工具）；罗素、摩尔斥为相对主义；新实用主义（罗蒂）继续争论。

> **立论/易错**："有用"＝在经验中可兑现、能指导行动；须与尼采视角主义区分。

## 八、跨阶段专题（论述主战场）

### Q48 〔北15〕 理念论与分有：柏拉图—亚里士多德—普罗提诺—阿奎那

**答题要点**

1. **柏拉图**：理念分离且可被**分有**（methexis）；困境——分有如何发生、**第三人难题**、理念自我谓述（北 15；详见 Q7）。
2. **亚里士多德**：把形式**内在化**——形式在事物中即本质；"分有"是空洞的诗喻，以潜能现实解释生成（Q9）。
3. **普罗提诺：太一与流溢**（北 24）：太一超越存在与思维、不可言说；万物由太一"**流溢**"——理智→灵魂→物质；恶是缺乏；回返与神秘合一（华师 16）。
4. **奥古斯丁与阿奎那**：奥古斯丁以"光照"替代分有；阿奎那以"**分有**（participatio）＋类比"说明受造物分有上帝的存在，但本质与存在实在区分（Q18）。

> **立论/易错**：分有说的困难是"一与多"；普罗提诺的流溢非创造（必然溢出、无意志）。

### Q49 〔北19〕 上帝存在的证明：安瑟尔谟—阿奎那—笛卡尔—康德

**答题要点**

1. **安瑟尔谟（本体论/先天）**：上帝＝"不能设想比之更伟大者"；若只在心中则不如"既在心中又在现实中"伟大→故必存在（华师 25、西电 25）；"我信以便理解"。
2. **高尼罗与阿奎那**：高尼罗以"完美岛屿"反驳；阿奎那**拒绝**先天证明（上帝存在非自明），改走五路后验（北 23）。
3. **笛卡尔**：第三沉思两个证明＋第五沉思本体论证明（存在是完满性）——"笛卡尔循环"争议（Q21）。
4. **康德的反驳**："**存在不是实在的谓词**"——一百塔勒：概念中的钱与口袋中的钱概念内容相同；存在是设定而非属性，故本体论证明无效（Q32）。

> **立论/易错**：先天/后验之分是理解谱系的钥匙；本体论证明的现代形态仍活。

### Q50 〔北15〕 共相问题：波菲利问题、唯实论与唯名论

**答题要点**

1. **波菲利问题**（三问）：种属是实在还是纯思想？若实在，有形还是无形？若无形，是否与可感物分离？（北 15/16）
2. **波爱修**：共相"作为整体而非部分、同时而非接续、内嵌而非外在"被分有——在事物中，而在思想中被抽象。
3. **唯实论与唯名论**：极端唯实论（共相先于事物）；极端唯名论（罗瑟林 flatus vocis）；温和：阿伯拉尔概念论、阿奎那"之前—之中—之后"（Q18）。
4. **奥卡姆与意义**：共相只是心灵符号，个别为唯一实在（Q19）；共相之争培育逻辑—语言分析，是分析哲学最远的祖先。

> **易错**：波菲利问题与共相之争是"同一问题的提问与回答"；阿伯拉尔既非极端唯实也非极端唯名。

### Q51 〔华师10〕 身心关系：笛卡尔—偶因论—前定和谐—平行论—赖尔

**答题要点**

1. **笛卡尔二元论**：思维实体与广延实体截然二分；交互靠松果体（失败）——心如何推动身无法解释（华师 24、北 15/17）。
2. **偶因论（马勒布朗士）**：身心交互只是"**偶因**"，真正因果唯有上帝；"在上帝中看见一切"（华师 10）。
3. **前定和谐与平行论**：莱布尼茨——上帝预定单子一致，身心如两座钟同步（Q23）；斯宾诺莎——思维与广延是同一实体的两属性，互不因果（Q22）。
4. **赖尔与现代**：范畴谬误把心灵当并列实体（Q44）；现代同一论、功能主义、现象意识之争。

> **立论/易错**：偶因论/前定和谐/平行论都是"取消交互"的策略，差别在谁是真正原因。

### Q52 〔华师21〕 实体学说：亚里士多德—笛卡尔—斯宾诺莎—莱布尼茨—黑格尔

**答题要点**

1. **亚里士多德**：实体＝个别事物（第一实体），形式/本质为其根据；"既不述说主体也不在主体之中"（Q10）；"严格定义的实体不可能是质料"（北 24）。
2. **笛卡尔**：实体＝不需他物即能存在者（严格唯上帝）；思维与广延是两类被造实体（Q20/Q21）。
3. **斯宾诺莎**：唯一实体＝神＝自然（自因）；属性/样态；规定即否定；反目的论（Q22）。
4. **莱布尼茨与黑格尔**：单子（多、无窗，Q23）；黑格尔——**实体即主体**，实体是自我展开的过程，批判斯宾诺莎"无世界"与莱布尼茨"无窗户"（Q35）。

> **立论/易错**：实体问题的变奏是一与多、必然与自由、静止与活动。

### Q53 〔华师22〕 因果性问题：休谟与康德

**答题要点**

1. **休谟的挑战**：因果必然性无印象对应——只有接近、接续、恒常会合；必然性是心灵习惯；归纳无理性基础（Q28）。
2. **康德的回应**：因果性是知性的**先天范畴**——"一切发生的事都以某物为前提"是经验可能性的条件，故因果判断对现象界有客观有效性。
3. **回应的限度**：只对现象有效，物自体不可知；"客观必然性"是经验的必然性；从范畴推出具体因果律（图型、经验类比）仍是难题。
4. **后续**：穆勒归纳五法、维也纳学派（因果＝函数依赖）、干预主义（伍德沃德）。

> **立论/易错**："回应是否成功"两面讲：保住科学必然性，代价是现象主义＋物自体不可知。

### Q54 〔华师24〕 经验论与唯理论的对立及康德的调和

**答题要点**

1. **共同前提**：主客二分、基础主义、以"观念"为材料。发展过程（华大 11/12/18）：经验论＝培根—霍布斯—洛克—贝克莱—休谟；唯理论＝笛卡尔—斯宾诺莎—莱布尼茨。
2. **分歧**：来源（感觉/反省 vs 天赋观念/理性直觉）、方法（归纳观察 vs 演绎几何）、实体（悬置或否定 vs 设定）、真理标准（印象对应 vs 清楚明白）。
3. **两条路线与唯心主义根源**（华大 11）：实质是知识的源泉与可靠性之争；唯心主义根源在于片面夸大感觉或理性环节、封闭于意识。
4. **康德调和**：内容（经验）＋形式（唯理论）＝**先天综合判断**，现象/物自体之分——"思维无内容是空的，直观无概念是盲的"（Q31）；评价：同一框架内两条路径，非简单对立。

> **立论/易错**：不要写成"一派错、一派对"；采分点在"康德用先天综合把两派接起来"。

### Q55 〔北22〕 自由与道德：奥古斯丁—阿奎那—康德—黑格尔

**答题要点**

1. **奥古斯丁**：自由意志是恶的可能根源；原罪后自由被损伤，"真正的自由"是"不能犯罪"（靠恩典恢复）；自由与预知相容（上帝在时间之外）（Q17）。
2. **阿奎那**：意志必然欲求普遍善，但对具体手段自由选择；自由是理性与意志的合作；"**恩典不摧毁自然，而是成全自然**"（Q18）。
3. **康德**：自由是道德律的存在根据、道德律是自由的认识根据；自律＝意志给自己立法；"你应当，故你能"；自由为悬设（Q32）。
4. **黑格尔与"道德/伦理"之辨**（北 22）：自由是"在他者中守在自己那里"；道德（Moralität）须上升为伦理（Sittlichkeit：家庭—市民社会—国家），批康德形式主义与"应当"的空洞。

> **立论/易错**：区分"自由意志（形而上学）"与"道德自由（规范）"；三家的"自由"含义不同。

### N1 〔中大〕阿那克萨戈拉的"种子"与"努斯"
**答题要点**
1. **种子（spermata）**：万物由无限多、性质各异的"种子"混合而成，"一切在一切之中"；生成是种子的**分离与混合**，而非从无到有。
2. **努斯（nous）**：安排宇宙的理性/心灵，是**最初的推动者**与秩序因；"努斯"使混沌中生出秩序。
3. **哲学史地位**：①第一次把"**理性**"作为宇宙的解释原则（苏格拉底、柏拉图、亚里士多德都承此）；②但亚里士多德批评他"只在解释必然性时才求助努斯"（目的论不彻底）。
4. **与原子论之别**：种子是**质的**（有性质），原子是**量的**（形状大小），后者更能解释机械论。

### N2 〔中大〕奥古斯丁：恶的"无效因"与"我可错，故我在"
**答题要点**
1. **恶是善的缺乏**（privatio boni）：恶非实体，而是意志**背离永恒者转向可变者**的结果；"无效因"（causa deficiens）——不是上帝造成，而是意志自身"缺失"。
2. **"我可错，故我在"**（si enim fallor, sum，《上帝之城》）：即使我怀疑、犯错，"**我存在**"也不可怀疑——比笛卡尔早一千余年的"我思"式论证。
3. **与笛卡尔之别**：奥古斯丁的确定性的最终落点是**上帝**（"我存在、我活着、我理解"都指向真理之光）；笛卡尔落点是**思维主体**，并以上帝保证清楚明白。
4. **思想关联**：两人都用"怀疑/犯错"作为**不可怀疑的支点**，但奥古斯丁是**信仰寻求理解**的路径，笛卡尔是**重建知识基础**的路径。
> **立论**：中山常把二者并考，落点是"**确定性的最终根据**不同：上帝 vs 自我"。

### N3 〔中大〕柏拉图《智者篇》"通种论"
**答题要点**
1. **问题**：如果"存在"与"非存在"绝对对立，则"错误"与"虚假陈述"不可能——智者就可逃入"非存在不可言说"的庇护。
2. **通种（megista genē）**：存在、同一、差异、运动、静止五个"最大的种"，彼此**可分有、可结合**；故"非存在"不是"无"，而是"**异于存在**"。
3. **结论**："非存在"以"差异"的方式存在，因此**虚假判断与虚假陈述可能**——为逻各斯（陈述）理论奠基。
4. **意义**：柏拉图晚期"理念论"的自我修正（《巴门尼德篇》提出诘难，《智者篇》给出回应），是**范畴论**与**逻辑学**的开端。

### N4 〔中大〕《巴门尼德篇》对理念论的诘难
**答题要点**
1. **分有的困境**：事物"分有"理念，是分有其**整体**还是**部分**？整体分有则理念不在任何一处；部分分有则理念本身被分割。
2. **第三人难题**（regressus ad infinitum）：若具体事物因"分有人的理念"而为人，则"人的理念"与具体的人之间还需一个"第三个人"的理念，无穷倒退。
3. **分离问题**：若理念与事物分离，则理念**不可被认识**，神的知识与人的知识脱节。
4. **柏拉图的回应**：区分"**分有**"的多种方式（《斐德罗》《智者篇》），或在"通种论"框架下重新理解；学界一般认为柏拉图**未彻底解决**，亚里士多德的批判（见 Q 区）正由此而来。
> **立论**：此题的价值在于——**理念论的最大敌人不是别人，是柏拉图自己**。

### N5 〔中大〕亚里士多德：质形论、第一实体、理智德性与道德德性
**答题要点**
1. **质形论（hylomorphism）**：具体事物＝质料＋形式；形式是"**这个**"（tode ti）即现实性，质料是潜能；灵魂是身体的**形式**（"灵魂是活的身体的现实"）。
2. **第一实体**：个别事物（"这个某人"）为第一实体；**种属**为第二实体；**质料不是严格意义的实体**（因为不可分离、不可定义）。
3. **理智德性 vs 道德德性**（《尼各马可伦理学》第六卷）：理智德性（智慧 sophia、明智 phronesis）通过**教导**获得；道德德性（勇敢、节制）通过**习惯**养成；二者以**明智**为枢纽——明智使道德德性"瞄准正确目标"。
4. **"幸福是理性灵魂的实现"**：幸福（eudaimonia）是灵魂**合于德性的现实活动**，非快乐、非荣誉、非潜能状态；外在善只是条件。
5. **中道**：德性是在"过"与"不及"之间由**明智**确定的适度（不是算术平均）。
> **易错**：亚里士多德不是"中庸主义"——中道是**由理性规定的恰当**，且"有些行为本身即恶，无中道可言"。

### N6 〔中大〕普罗提诺的"流溢说"（emanation）
**答题要点**
1. **太一（hen）**：绝对单一、超越存在与思想；不可言说，只能"否定神学"地逼近。
2. **流溢**：太一因"**丰盈**"（not deficiency）而流出——努斯（理智）→ 灵魂 → 感性世界；流溢不减少太一（如太阳发光而不损自身）。
3. **回转（epistrophē）**：流出者因"观照"太一而获得形式与存在——**流溢与回转**构成循环。
4. **恶的问题**：恶是"**离太一最远**"的质料/无序，是善的**匮乏**（与奥古斯丁同构）。
5. **影响**：奥古斯丁、伪狄奥尼修斯、中世纪神秘主义、德国古典（谢林、黑格尔"绝对"的自我展开）。

### N7 〔中大〕唯名论与实在论之争及其后世影响
**答题要点**
1. **问题**：共相（种属）是**实在**（res）还是**名称**（nomen/flatus vocis）？
2. **极端实在论**（安瑟尔谟）：共相先于事物、独立实在；**极端唯名论**（罗瑟林）：共相只是语音；**温和**（阿伯拉尔概念论、托马斯三说）。
3. **奥卡姆**：剃刀原则（"如无必要勿增实体"）→ 共相是心灵的**自然符号**，个别是唯一实在——为**经验论与个体主义**开路。
4. **后世影响**：①近代**认识论转向**（从"事物本质"转到"观念/词项"）；②**逻辑与语言分析**（词项逻辑、指代理论）；③政治思想上的**个体主义**（自然权利论）。

### N8 〔中大〕芝诺《理想国》与柏拉图《理想国》
**答题要点**
1. **柏拉图《理想国》**：以**哲学王**与**三阶层分工**（统治者—护卫者—生产者）为纲，正义＝各部分各司其职；废除私有财产与家庭（护卫者阶层）、男女同等教育。
2. **芝诺（斯多亚创始人）《理想国》**：构想一个**世界城邦**（cosmopolis）——智者即公民、**无阶级、无国界、无神庙**，以**自然法/理性**为唯一纽带；亦主张共妻共子。
3. **差异**：柏拉图仍以**城邦（polis）**为单位并保留等级；芝诺以**宇宙（kosmos）**为单位、以**理性平等**消解等级。
4. **理论意义**：前者是**政治哲学的理想建构**（含等级），后者是**斯多亚世界主义**的原型（含平等）——中世纪自然法、康德世界公民法权都可上溯。

### N9 〔中大〕原子论者的"流射说"与"约定论"的矛盾
**答题要点**
1. **流射说（aporroia）**：物体表面发出**影像粒子**，进入感官形成知觉——认识是**物理的、被动的**过程。
2. **约定论（nomos）**：德谟克利特"甜是约定，苦是约定，热是约定，冷是约定，**实际上只有原子与虚空**"——第二性质是**主体约定**，非事物固有。
3. **张力**：若知觉由流射决定，则感官应当**可靠**；但约定论又说感官报告的性质**非真实**——认识论上的自我削弱（后被怀疑派利用）。
4. **意义**：这是**第一性质/第二性质**学说的最早版本（见洛克 Q），也是"**科学实在论 vs 现象主义**"的古代原型。

### N10 〔中大〕司各脱的"此性"（haecceitas）
**答题要点**
1. **问题**：托马斯认为个体化原则是**质料**（materia signata）；司各脱反对——质料本身是共同的，不能说明"这个"。
2. **此性**：个体之所以为**不可替代的这一个**的"终极实在性"（haecceitas），是**形式**层面的个体化原则。
3. **"形式区分"**：同一事物中，性质（共性）与此性（个体性）是**同一实在**的两种"形式上的"区分（distinctio formalis），非实在分割。
4. **影响**：为**个体性**与**自由意志**张目（意志高于理智：自由非由认识决定），并影响海德格尔式的"此在的独一性"讨论。

### N11 〔中大〕康德的"先验唯心论"与"法权/德性之别"
**答题要点**
1. **先验唯心论**：时空与范畴是**主体的先天形式**，经验对象由此构成；"**经验的实在论**"与"**先验的观念论**"是一体两面（见 Q 区哥白尼革命）。
2. **正当（Recht）与德性（Tugend）**：《道德形而上学》分**法权论**与**德性论**——法权只约束**外在行为**（可强制），德性约束**内在动机**（不可强制）。
3. **法权法则 vs 道德法则**：①法权的普遍法则只要求"**外在自由**的共存"；②道德法则（绝对命令）要求"**同时以人为目的**"；③前者是**许可的强制**，后者是**自律的义务**。
4. **意义**：康德把"**合法性（Legalität）**"与"**道德性（Moralität）**"分开——这解释了为何"守法的人未必有德"。

### N12 〔中大〕黑格尔：感性确定性、逻辑是概念的自身运动、"真实是无限"
**答题要点**
1. **感性确定性**（《精神现象学》开端）：以为"这一个、这时、这里"最确定，但一经说出即**消逝为普遍物**——确定性自我否定，故必须上升。
2. **"逻辑是概念的自身运动"**：概念不是静态形式，而是**自我规定、自我展开**的活动；范畴的推演就是**思想自身的运动史**。
3. **"真实是无限"**：①"坏的无限"（恶无限）＝无穷递进（1,2,3…）；②"**真无限**"＝在有限之中**自身关联**、自我规定的整体（"真正的无限"是圆圈）。
4. **意义**：三者共同构成黑格尔对**康德"知性/有限"**的批判——真理不是界限内的知识，而是**总体性的自我展开**。

### N13 〔中大·题型〕文献材料题答法
**答题要点（模板）**
1. **识别**：先判断文本归属（用词特征：transzendental、绝对精神、此性、种子、流溢…）——中山常给**中译原文+出处提示**。
2. **复述**：用两三句把材料论点**转写**为自己的话，标出其**结论句**。
3. **学理定位**：该论点针对什么问题/对手（如"悬置知识以便为信仰腾出地盘"针对知识僭越）。
4. **展开**：概念链（现象/物自体/自由/悬设），必要时补原文其他段落。
5. **评价**：给出**自己的判断 + 一条反驳**（中山论述几乎必问"你是否赞同/给出理由"）。
> **高频材料**：康德《纯批》第二版序（"悬置知识……"）、康德法权论、休谟因果段、《理想国》洞穴/太阳段、黑格尔《精神现象学》序（"实体即主体"）、普罗提诺流溢段、亚里士多德《论灵魂》灵魂—身体段。

## 十二、现代西哲补强（南京大学 2003—2017 现代西哲卷 + 全国 67 校高频）

> 南大「现代西方哲学」单列一卷（2003—2017 全），是全国唯一把现代西哲考成独立科目的 985 之一，人物密度高；叠加思庐 67 校高频词，把前面 Q37—Q47 未覆盖的补全。
> 注：Q37—Q47 已含叔本华/尼采/胡塞尔/海德格尔/萨特/弗雷格/罗素/维特根斯坦/赖尔/普特南/克里普克/詹姆斯，本节不再重复。

### N1 〔南大03/04/05/13〕柏格森：绵延、直觉与"两种时间"
**答题要点**
1. **绵延（durée）**：真正的实在不是空间化的"时间"，而是**连绵不断、不可分割的流动**；"绵延"＝内在意识流的连续。
2. **两种时间**：①**空间化时间**（钟表时间，可分割、均质，对应科学）；②**真实时间**（绵延，不可分割，对应生命意识）。
3. **直觉**：把握绵延/生命的方法，与**分析（理智）**对立——理智只能切割静止的材料，直觉才能进入生命本身。
4. **生命冲动（élan vital）**：万物进化由内在的生命冲动推动；与机械论、目的论都不同（《创造进化论》）。
5. **地位**：法国生命哲学的代表，反实证主义；影响德勒兹、梅洛-庞蒂、怀特海。
> **易错**：绵延不是"主观时间"这么简单，是**把时间从空间化中解救出来**的本体论努力。

### N2 〔北21/南大03/04/06/08/14〕波普尔：证伪主义、世界三
**答题要点**
1. **科学划界**：不是"可证实"而是"**可证伪**"（falsifiability）——一个理论科学与否，在于它**原则上能被经验反驳**。
2. **反归纳**：归纳无论从逻辑（休谟）还是实际都不可靠；科学靠**猜想—反驳**（conjecture & refutation）前进：P1→TT→EE→P2。
3. **试错法**：知识通过"大胆猜想 + 严格检验"进化；"我们是从错误中学习"。
4. **三个世界**：世界一（物理）、世界二（心理）、世界三（客观知识的产物：理论、问题、书籍）——世界三有自主性（但被批判为"三重实在"的空想）。
5. **历史决定论批判**：《历史决定论的贫困》——历史无必然规律，社会工程只能"渐进"（piecemeal）不能"乌托邦式"整体设计。
> **立论**：证伪主义与"精致证伪主义"（拉卡托斯）、库恩范式论构成当代科哲三足。

### N3 〔南大03/05/06/08/09〕库恩：范式与科学革命
**答题要点**
1. **范式（paradigm）**：一个科学共同体共有的**范例、承诺、解题标准**的综合体（"常规科学"赖以运行的框架）。
2. **科学发展的结构**：前科学→常规科学（在范式内"解谜"）→**反常**积累→危机→**科学革命**（范式更替）→新常规科学。
3. **不可通约性（incommensurability）**：前后范式之间**无法用中立标准比较**（语汇、方法、世界本身都变了），故有"相对主义"之嫌。
4. **对波普尔的批评**：科学常态不是"证伪"而是**在范式内解决问题**；革命才是例外。
5. **与波普尔/拉卡托斯的关系**：波普尔重"革命"，库恩重"常规"；拉卡托斯以"研究纲领"（硬核+保护带）调和二者。
> **易错**：范式不是一句"世界观"口号，要落到**常规科学/解谜/反常/革命**四个环节。

### N4 〔南大10/12/北22〕奎因：经验论的两个教条、本体论承诺、译不准
**答题要点**
1. **两个教条**（《经验论的两个教条》，1951）：①**分析/综合的区分**；②**还原论**（一切有意义的陈述可还原为关于直接经验的陈述）——两者都可被经验"整体地"反驳。
2. **整体论（holism）**："我们关于外在世界的陈述不是个别地，而是**作为一个整体**面对经验法庭的"——任何陈述原则上都是**可修正**的，包括逻辑与数学。
3. **本体论承诺**："**存在就是成为变元的值**"（To be is to be the value of a variable）——通过一阶量化式判断一个理论承诺了哪些实体。
4. **译不准原则**：把一种语言翻译为另一种时，存在多套互不兼容却同样成立的翻译方案（"gavagai"）——指称的不确定性。
5. **意义**：奎因把经验主义推向**逻辑与自然化认识论**，是分析哲学"后经验主义"的转折点。
> **立论**：两个教条的后果是**摧毁了"先天必然"的独立王国**，此题是南大高频（03/10/12 三次）。

### N5 〔南大03/04/06/10/11/14〕罗蒂：反本质主义、自然之镜、新实用主义
**答题要点**
1. **《哲学与自然之镜》（1979）**：批判**表象主义认识论**——把心灵当作"反映自然的镜子"，哲学以为自己在提供"知识的根基"。
2. **反本质主义/反基础主义**：没有"真的本质"或"最终的辞典"；真理不是"符合实在"，而是**共同体成员之间达成的有用一致**。
3. **新实用主义**：接续杜威、詹姆斯的实用主义，把哲学从"知识论"转向"**教化**"（edification）与**对话**（把哲学当作文化批判而非法庭）。
4. **后哲学文化**：哲学与文学、艺术、历史**平起平坐**，不再是"文化的基础学科"。
5. **影响与批评**：与哈贝马斯论战（"语境的偶然性 vs 普遍有效性"）；被指责为**相对主义**。
> **立论**：罗蒂把"认识论转向"反转为"**解释学转向**"，是后现代分析哲学的代表。

### N6 〔南大03/05/08/10/14〕德里达：解构、踪迹、逻各斯中心主义
**答题要点**
1. **逻各斯中心主义**：西方形而上学预设"**在场**"的终极意义（语言是传达思想的透明工具，思想直接"在场"）——德里达称此为"语音中心主义"。
2. **解构（déconstruction）**：不是摧毁，而是**松动文本内部的二元对立**（在场/缺席、本质/现象、言说/书写），暴露其一贯依赖被压抑的对立面。
3. **延异（différance）**：意义的产生靠**差异**与**延宕**，故意义永远**不封闭、不在场**；"书写"优先于"言说"。
4. **踪迹（trace）**：每个符号的意义都是此前符号踪迹的**重复—改写**，无最终所指。
5. **影响**：文学批评、法哲学（德沃金—菲什之争）、女性主义；批评者指责其为"文字游戏/虚无主义"。
> **易错**：解构不是"怎么都行"，而是**对"终极基础"的持续质疑**。

### N7 〔南大08/12〕索绪尔：能指与所指、结构主义语言学
**答题要点**
1. **语言符号的任意性**：能指（signifiant，音响形象）与所指（signifié，概念）的结合是**任意的、约定俗成**的。
2. **语言 vs 言语**：语言（langue）是社会性的**规则系统**，言语（parole）是个体的具体使用；语言学研究对象是 langue。
3. **共时 vs 历时**：共时（系统状态）优先于历时（演变），意义来自**系统内差异**（"语言中只有差异"）。
4. **意义**：为**结构主义**（列维-斯特劳斯、巴特、拉康、福柯早期）提供方法论范式——**关系/差异优先于实体**。
> **立论**：索绪尔是"结构主义之父"，但其任意性与差异思想又被德里达发展为"解构"。

### N8 〔南大11〕拉康：镜像阶段
**答题要点**
1. **镜像阶段（6—18 个月）**：婴儿在镜中认出自己的完整形象，却把这"理想的我"误认为自我——自我（moi）从一开始就是**想象性的误认**。
2. **三分结构**：**想象界**（Imaginaire，形象/误认）↔ **象征界**（Symbolique，语言/大他者/法则）↔ **实在界**（Réel，无法象征化的缺口）。
3. **回归弗洛伊德**：以索绪尔语言学重读弗洛伊德，"**无意识像语言一样被结构**"。
4. **欲望**：人的欲望是"**他者的欲望**"——通过大他者（语言、社会法则）的中介形成。
5. **影响**：齐泽克、阿尔都塞（把拉康用于意识形态"询唤"）、女性主义。
> **易错**：镜像阶段不是"自我意识的形成"，而是**自我=误认**这一反笛卡尔式的结论。

### N9 〔南大10/11/12/14〕梅洛-庞蒂：身体主体与知觉的优先性
**答题要点**
1. **身体主体（corps-sujet）**：既非纯意识（笛卡尔），也非纯生理——**身体就是表达意义的原初媒介**，是"在世界之中"的存在。
2. **知觉的优先地位**（《知觉现象学》）：知觉是**前谓词、前反思**的，是科学、概念的**奠基**层；反对把知觉还原为感觉原子（经验论）或理智构造（唯理论）。
3. **对笛卡尔二元论的批判**："我"首先不是"思维"，而是"**我能**"（身体的各种运动能力）。
4. **格式塔与生活世界**：承格式塔心理学与胡塞尔"生活世界"，但把**本己身体**作为世界显现的枢纽。
5. **地位**：现象学的"**身体转向**"——从"意识"推进到"肉身存在"，影响当代身体哲学。
> **立论**：梅洛-庞蒂是胡塞尔之后现象学最重要的内部发展（身体/知觉维度）。

### N10 〔南大08/09/11/12/14〕伽达默尔：视域融合、效果历史、哲学诠释学
**答题要点**
1. **哲学诠释学**（《真理与方法》）：理解不是**方法**，而是**此在的存在方式**（承海德格尔的"存在论转向"）。
2. **视域融合**：理解＝解释者的视域与文本的视域**相互融合**；没有"客观中立的原义"，也非"任意主观"。
3. **效果历史（Wirkungsgeschichte）**：任何理解都已**历史地被效果规定**——历史既在理解之中，又先于理解。
4. **前见（Vorurteil）的合法性**：前见不是障碍，而是理解得以可能的条件（反对启蒙对前见的全盘否定）。
5. **与哈贝马斯之争**：伽达默尔强调"传统/对话"，哈贝马斯担心其会**取消批判**（需要"意识形态批判"与"效果历史的反思"结合）。
> **易错**：视域融合不是"各退一步的折中"，而是**理解本身的结构**。

### N11 〔南大06/08/11/14〕罗尔斯 vs 诺齐克：正义论与自由至上主义
**答题要点**
1. **罗尔斯《正义论》**：①原初状态 + **无知之幕**（不知自己的社会位置）→ 正义诸原则；②第一原则——**平等的自由**；③第二原则——机会公平 + **差别原则**（不平等只有在对最不利者有利时才被允许）。
2. **批判功利主义**：功利主义允许牺牲少数人的利益换取总量最大化，罗尔斯反对之（"每个人都拥有一种基于正义的不可侵犯性"）。
3. **诺齐克《无政府、国家与乌托邦》**：**自由至上主义**——只有个人权利是神圣的；主张**最小国家**（watchman state）。
4. **对罗尔斯的批评**：①"持有的正义"（获取、转让、矫正三道程序）取代"分配的正义"；②差别原则是**对个人的强迫性再分配**，侵犯财产权；③"模式化"分配要求不断干预自由市场。
5. **焦点**：**自由优先 vs 平等优先**；"应得 vs 权利"——当代政治哲学的主战场。
> **立论**：罗尔斯把康德式契约论改造为**正义理论**，诺齐克则以洛克式权利论回击。

### N12 〔南大06/07/08/09/20〕功利主义：边沁与密尔（及罗尔斯批判）
**答题要点**
1. **边沁（古典功利主义）**：行为对错取决于**苦乐后果**；"最大多数人的最大幸福"；**幸福的计算**（强度、时长、确定性、远近、广度等七维）。
2. **密尔（修正）**：①快乐有**质的差别**（"宁做不满足的苏格拉底，不做满足的猪"），非纯"量"；②由**行为功利主义**趋向**规则功利主义**；③《论自由》以"伤害原则"划出个人自由边界。
3. **理论困难**：如何**计算总幸福**？是否允许牺牲无辜？"最大多数人最大幸福"与正义的冲突。
4. **罗尔斯的批判**：功利主义**不尊重个体分离性**（把社会当作单个利益总量的承载者）。
5. **地位**：是现代伦理学与政治经济学的基础之一，与康德的**义务论**对立（见 Q 区康德绝对命令）。
> **立论**：功利主义是"**后果论**"的顶点，答题务必与"道义论/义务论"对比。

### N13 〔南大03/04/08/09/12〕孔德、马赫与逻辑实证主义：拒斥形而上学
**答题要点**
1. **孔德（实证主义）**：人类认识三阶段——**神学→形而上学→实证（科学）**；"社会动力学/社会静力学"；科学即"描述现象的规律"，不问"本质/第一因"。
2. **马赫（经验批判主义）**：**思维经济原则**（科学是经济地整理经验）；要素（感觉）一元论；"物是感觉的复合"——被列宁《唯批》批判为主观唯心主义。
3. **逻辑实证主义（维也纳学派）**：①**意义标准＝可证实原则**；②两种陈述——**分析（逻辑/数学）**与**综合（经验科学）**，其余（形而上学、伦理、神学）**无认知意义**；③哲学变成"语言的逻辑分析"。
4. **拒斥形而上学的两种方式**：实证主义以"**不可证实**"拒斥，维特根斯坦（《逻辑哲学论》）以"**不可言说**"悬置（"对不可说的必须沉默"）。
5. **困境**：可证实原则本身不可证实；被奎因"两个教条"（见 N4）、波普尔证伪主义（见 N2）所化解。
> **立论**：此题是南大高频（03/04/06/08/09/12 多次），要点是**把三者串成"拒斥形而上学"的一条线**。
