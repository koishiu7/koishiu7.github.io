## 一、古希腊

### Q1 米利都学派（泰勒斯、阿那克西曼德、阿那克西美尼）

**答题要点**

1. **问题转向**：从神话（神谱）转向"**本原（archē）**"——万物由什么构成、如何生成。
2. **泰勒斯**："水是万物的本原"——以**自然本身**解释自然，且水有流动性、可生养万物。
3. **阿那克西曼德**："无定（apeiron）"——本原不能是任何具体元素，否则会被对立面消灭；"无定"通过"分离"生成万物，含"补偿"（adikia）观念。
4. **阿那克西美尼**："气"——以稀薄/凝聚解释万物差异，提出**量变生质变**的雏形。

> **易错**：不要用"唯物 vs 唯心"套娃式评价米利都；其意义是**理性解释的开端**与**本原问题的确立**。

### Q2 毕达哥拉斯的"数本原"

**答题要点**

1. **数是本原**：万物皆数以成形（和谐、比例、秩序）；"数是一切事物的本质"。
2. **理据**：音乐和声、天体运行、几何比例都可还原为数的关系——**秩序可数学化**。
3. **灵魂学说**：灵魂不朽、轮回、净化（与数的和谐相应）。
4. **意义**：为柏拉图理念论提供"**形式/秩序优先**"的模型；也开西方"数学—形而上学"传统（至笛卡尔、莱布尼茨、康德）。

### Q3 ★ 巴门尼德的"存在"与真理/意见之分

**答题要点**

1. **两条路**：真理之路（"存在者存在，不存在者不存在"）与意见之路（ mortal 的"既存在又不存在"）。
2. **存在的特征**：不生不灭、不可分、不动、完满（像一个球体）——**思想与存在同一**（"能思维的和所思维的乃是同一"）。
3. **对后世**：①确立**本体论**问题（何为真实存在）；②"现象与实在"的二分成为西方形而上学主线（柏拉图、康德）。
4. **芝诺悖论**（飞矢不动、阿基里斯与龟）：以归谬捍卫"存在是一、不动"，同时**暴露了运动与时空的连续性难题**，是辩证法的前史。

> **易错**："存在"（to eon）不是"存在者"的集合，而是**使存在者得以存在的"一"**；不要把巴门尼德说成"唯心主义"。

### Q4 ★ 智者派与普罗泰戈拉"人是万物的尺度"

**答题要点**

1. **转向**：从"自然（physis）"转向"**人—nomos（礼法/约定）**"，讨论伦理、政治、修辞。
2. **"人是万物的尺度"**（普罗泰戈拉）：①**认识论**读法——事物对我显现如何，便如何（感觉主义/相对主义）；②**人文**读法——人是一切价值的中心。
3. **影响**：①打破自然崇拜与神意解释，**人是中心**；②相对主义导致"真理被抛弃"，辩论术取代求真（柏拉图批评智者是"说服的艺术"而非"真理的艺术"——参见本库 [[Nietzsche]] 中的同段评述）；③为苏格拉底—柏拉图"以定义求真理"提供反面刺激。
4. **高尔吉亚三命题**：无物存在；即使有也不能认识；即使认识也不能表达——**虚无主义+不可知论+语言怀疑**的极端形态。

> **易错**："人是尺度"不等于"人类中心主义"的现代意义；它在当时是**反神权、重约定**的启蒙命题。

### Q5 ★ 苏格拉底："美德即知识""精神助产术"

**答题要点**

1. **美德即知识**（arete = episteme）：无人自愿作恶，作恶源于无知；德性可教、有统一性（各种德性都是"知识"的同一件事）。
2. **精神助产术**（辩证法）：通过反问、归谬（elenchus）使对话者"自知无知"，再从具体事例归纳出定义——**概念定义法**的开端。
3. **"认识你自己"**：把哲学从自然转向**灵魂/德性**（"未经省察的人生不值得过"）。
4. **政治立场**：守法（《克里同》"恶法亦须守"的理由：城邦法律的正当性来自约定与养育），与智者"强权即正义"（色拉叙马霍斯）对立。
5. **与柏拉图的关系**：苏格拉底"求定义"，柏拉图把定义**实体化为理念**。

> **立论/易错**：美德即知识的难点是"**意志薄弱**"（akrasia）；后世（亚里士多德、休谟）都以反驳此命题确立自己的伦理学。

### Q6 ★ 柏拉图的理念论：洞穴喻、日喻与灵魂回忆

**答题要点**

1. **理念（idea/eidos）**：可感事物之外、永恒不变的"型相"，是事物的**所是**与价值标准；具体事物"分有"（methexis）或"摹仿"（mimesis）理念。
2. **洞穴喻**：囚徒（意见/影像）→ 转身（灵魂转向）→ 走出洞穴（认识理念）→ 见到太阳（善的理念）→ 返回洞穴（哲人治国）。
   - 对应"**线段喻**"的四层：影像—可感物—数学对象—理念，认识等级为猜测—信念—理智—理性。
3. **日喻**：善理念如太阳，既使事物**存在**（可见），又使灵魂**认识**（可知）——善是**存在与认识的共同根据**。
4. **灵魂回忆说**（《美诺》）：知识是灵魂对前世所见理念的回忆，"学习即回忆"；由"美诺悖论"（不知者如何求索）逼出。
5. **灵魂三分**（理性/激情/欲望）与**正义**：各部分各司其职即正义，对应理想国的三阶层。
6. **证明灵魂存在**：①相反相生（生—死循环）；②回忆说（知识先于经验）；③灵魂与生命本质同一（灵魂是"生命的理念"，不能容纳死亡）。

> **立论/易错**：洞穴喻的要点是"**教育不是灌注而是转向**"（periagoge），且返回洞穴意味着**哲学的政治责任**。理念论的困难是"第三人难题"（分有需要一个第三者），这正是亚里士多德批判的入口。

### Q7 ★ 亚里士多德对柏拉图理念论的批判与"四因说"

**答题要点**

1. **批判要点**：①理念与事物**分离**（chorismos），无法解释运动与生成；②"分有"是空话（未说明如何分有）；③"第三人"无穷倒退；④理念不解释可感世界的秩序，反而多设一套世界。
2. **实体（ousia）**：第一实体是个别事物（"这个"），第二实体是种属；实体是"**既不可述说主体又不存在于主体之中**"的东西。
3. **四因**：质料因、形式因、动力因、目的因；后三者常可合一为"形式"。
4. **潜能与现实（dynamis/energeia）**：生成是"潜能→现实"的实现过程（"人是理性动物"即形式在质料中的实现）；这解决了柏拉图无法解释的**运动**问题。
5. **形式与质料**：形式是"使某物成为某物"的本质（"灵魂是身体的形式"），二者在具体事物中**不可分离**。
6. **不动的推动者**：为解释永恒运动，需一个纯形式、纯现实的"第一推动者"——被后世神学（托马斯）接续。

> **立论/易错**：亚里士多德不是"抛弃理念"而是**把形式内在化**（形式在事物之中）。答"形式因与质料因的关系及其影响"时，务必讲"**潜能—现实**"与"**目的论**"两条线。

### Q8 ★ 伊壁鸠鲁、斯多亚与怀疑派（希腊化三派）

**答题要点**

1. **伊壁鸠鲁**：①原子论（原子+虚空，原子有**偏斜** clinamen→ 自由的可能）；②快乐主义（快乐=身体无痛苦+灵魂无纷扰 ataraxia，非纵欲）；③感觉主义真理标准；④神不干预人间（破除恐惧）。
2. **斯多亚**：①**逻各斯**贯穿宇宙，宇宙是有理性的整体；②"顺应自然（理性）而生活"即德性即幸福；③命运必然，但**自由在于对必然的认识与态度**（"愿意的人命运领着走，不愿意的人命运拖着走"）；④世界城邦（cosmopolis）、平等（奴隶亦有人性）；⑤不动心（apatheia）。
3. **怀疑派（皮浪）**：事物不可判定（"悬搁判断" epoché），故应"不动心"；十式（现象差异、视角、感官相对等）——**为康德之前的独断论批判提供资源**。
4. **历史影响**：伊壁鸠鲁→ 近代原子论/功利主义；斯多亚→ 自然法、康德义务论的气质；怀疑派→ 蒙田、休谟。

## 二、中世纪与基督教哲学

### Q9 ★ 奥古斯丁：光照说、原罪与自由意志

**答题要点**

1. **光照说（illuminatio）**：人的理性如眼睛，需上帝之"光"才能认识永恒真理；真理不在感官而在**内心对上帝之光的分有**——柏拉图"日喻"的基督教版。
2. **信仰与理性**："**信仰寻求理解**"（credo ut intelligam）——先信后懂，理性为信仰服务但仍有独立地位（"若不信，则不能理解"）。
3. **原罪与自由意志**：恶不是实体而是"**善的缺乏**"（privatio boni）；始祖滥用自由意志而堕落，自此人性**被原罪损伤**，意志向恶倾斜（"非不能为善，而是不愿"）。
4. **恩典论**：得救不靠人的功德而靠**上帝恩典**（与佩拉纠之争）；后经奥古斯丁发展出"预定论"。
5. **时间学说**（《忏悔录》卷十一）：时间是"**心灵的三重延展**"——过去的现在（记忆）、现在的现在（直观）、将来的现在（期待）；上帝在时间之外。
6. **双城记**：上帝之城（爱上帝）与地上之城（爱自己）两种爱的秩序。

> **立论/易错**："原罪—自由意志—恩典"三者必须连贯讲：恶来自**自由意志的滥用**，但人已无力自救，故须恩典——这直接触发宗教改革（路德、加尔文）。

### Q10 ★ 安瑟尔谟的上帝存在证明（本体论证明）

**答题要点**

1. **论证**："上帝是最完满的存在者"；"存在于心中"不如"既在心中又在现实中"完满；故上帝必在现实中存在（"愚人心里说没有上帝"）。
2. **形式**：从**概念**推出**存在**（先天/本体论证明），不依赖经验。
3. **反驳**：①高尼罗"完美岛屿"类比（同法可证完美岛屿存在）——安瑟尔谟答：岛屿不是"最完满者"，只有无限完满者才能如此推论；②**康德**："存在不是实在的谓词"（一百塔勒的硬币：概念中的钱与口袋中的钱）；③现代分析哲学（刘易斯式模态论证）仍在讨论。
4. **地位**：西方哲学史上第一个**从概念到存在的先天证明**，后世（笛卡尔、莱布尼茨、黑格尔）反复重述。

### Q11 ★ 托马斯·阿奎那：五路证明、本质与存在

**答题要点**

1. **五路证明（后验证明，从经验出发）**：①运动（必有不动的推动者）；②因果（必有第一因）；③偶然与必然（必有必然存在者）；④完满性等级（必有最完满者）；⑤目的论（无理性的自然趋向目的，必有设计者）。
2. **与安瑟尔谟之别**：托马斯**不承认**先天本体论证明，坚持**后验**（从果推因）路径。
3. **本质（essentia）与存在（esse）的实在区分**：受造物中"是什么"与"是否"是两回事（本质不包含存在）；唯上帝是"存在本身"（ipsum esse），其本质即存在——这是上帝必然存在的形而上学根据。
4. **灵魂学说**：人是**理性灵魂与质料的复合实体**（不是柏拉图式"灵魂在身体里"），灵魂是身体的**形式**；理性灵魂不死。
5. **信仰与理性**：哲学（自然理性）与神学（启示）各有领域但不相矛盾，哲学是神学的婢女（"恩典不破坏自然，而使之完满"）。
6. **自然法**：永恒法→自然法→人法→神法，为近代自然权利论（格劳秀斯、洛克）铺路。

> **立论/易错**：五路的关键是"**从经验到超越**"的推论逻辑，答简答要把"第一因/必然存在"的不可无穷倒退原则说出来。

### Q12 ★ 共相之争：唯实论与唯名论

**答题要点**

1. **问题**：共相（种属概念）是**实在**还是**名称**？——"人类""白性"是否有独立存在。
2. **极端唯实论**（安瑟尔谟一系）：共相先于事物（universalia ante rem），只有共相是真实，个别是分有。
3. **极端唯名论**（罗瑟林）：共相只是名称（flatus vocis），个别才是实在。
4. **温和立场**：阿伯拉尔"概念论"（共相在事物之中但作为概念在心灵中）、托马斯"共相在事物之后/之中/之前"三重说法。
5. **奥卡姆的剃刀**："**如无必要，勿增实体**"（entia non sunt multiplicanda praeter necessitatem）——把共相还原为心灵的概念，倾向唯名论；直接导向近代**经验论与个体主义**。
6. **意义**：共相之争培育了**逻辑—语言分析**（词项逻辑、指代理论），是分析哲学最远的思想祖先。

### Q13 奥古斯丁的"上帝之城"与中世纪政治哲学

**答题要点**

1. **两种爱、两座城**：爱上帝以至于轻视自己 = 上帝之城；爱自己以至于轻视上帝 = 地上之城；两城在历史中交错，终末分离。
2. **历史神学**：历史有方向（创造—堕落—救赎—终末），打破循环史观。
3. **政治观**：政治权威是**原罪的结果**（必要的恶），但政权本身不等于正义；"没有正义的王国不过是强盗集团"。
4. **与托马斯对比**：托马斯更重**自然理性与政治的自主性**（亚里士多德式），奥古斯丁更重**恩典与终末**。

## 三、近代唯理论

### Q14 ★ 笛卡尔：普遍怀疑、"我思故我在"与身心关系

**答题要点**

1. **普遍怀疑（方法论怀疑）**：感官可欺、梦境不可辨、恶魔假设——凡可疑者一律悬置，目的是寻找**不可怀疑的基点**。
2. **我思故我在（cogito, ergo sum）**：怀疑本身证明"我在怀疑/思维"不可怀疑；"我"的本质是**思维（res cogitans）**——近代**主体性**的起点。
3. **上帝存在证明**：①从"我心中有完满者观念"推出完满者存在（观念的原因不能小于观念本身）；②本体论证明（完满者必含存在）——后人指责这是**笛卡尔循环**（用上帝保证清楚明白，又以清楚明白证上帝）。
4. **天赋观念**：上帝、自我、数学公理等观念为天赋（"天赋"≠ 现成，而是**倾向/能力**）。
5. **身心二元论**：思维实体（无广延）与广延实体（无思维）截然二分；交互问题由**松果体**说明（失败），成为近代哲学的核心难题（马勒布朗士"偶因论"、莱布尼茨"前定和谐"、斯宾诺莎"身心平行"都在解这个题）。
6. **清楚明白（clara et distincta perceptio）**：真理的**内在标志**。

> **立论/易错**：论述"我思故我在在哲学史上的影响"，要落到三条线：**主体性转向**（康德）、**身心问题**（平行论/偶因论/现象学）、**基础主义与怀疑论**（胡塞尔、分析哲学的反驳）。

### Q15 ★ 斯宾诺莎：实体、属性、样态与身心平行

**答题要点**

1. **实体=神=自然**（deus sive natura）：实体是"**自因**（causa sui）"——自己产生自己、不依赖他物；只有一个实体（**一元论**），故上帝与自然同一（泛神论）。
2. **属性（attribute）**：实体的本质；人只认识**思维**与**广延**两种（可能有无穷多）。
3. **样态（modus）**：实体的分殊/表现，即个别事物与心灵状态。
4. **身心平行论**：思维与广延是同一实体的两种属性，**一一对应、秩序相同但互不因果**——身体不能决定心灵，心灵不能决定身体。
5. **决定论与自由**："自由是对必然的认识"——一切皆必然，自由在于理解必然、依理性而生活（"不哭不笑，而是理解"）。
6. **"一切规定都是否定"**（omnis determinatio est negatio）：任何规定都是对无限实体的限制；个别事物是"否定性"的存在（华南 682 曾考此句）。
7. **方法**：几何学方法（定义—公理—命题—证明），追求**知识的确定性等级**（想象—理性—直观）。

> **立论/易错**：斯宾诺莎不是"无神论"也不是"唯物论"，是**中性一元论**；"神"没有意志与目的，这点与宗教人格神根本不同。

### Q16 ★ 莱布尼茨：单子论、前定和谐与两种真理

**答题要点**

1. **单子（monad）**：单纯、无部分、不可分的精神性实体；"**单子没有窗户**"——不受外物影响，其变化由内在本性展开（"隐德来希"）。
2. **前定和谐**：上帝在创造时已预定各单子的状态，使身心/万物"预定的和谐"地一致（解决笛卡尔身心交互问题，替代偶因论）。
3. **两种真理**：①**推理的真理**（vérités de raisonnement）——依**矛盾律**，其否定为不可能（逻辑、数学），必然；②**事实的真理**（vérités de fait）——依**充足理由律**，其否定仍可能，偶然。
4. **逻辑方法的改进**：①提出**普遍字符（characteristica universalis）+ 推理演算（calculus ratiocinator）**，把推理化归为计算——数理逻辑的先声；②**充足理由律**的明确提出；③可能世界理论（"最好的可能世界"）；④微积分（与牛顿独立发明）；⑤二进制。
5. **天赋观念**：观念作为**倾向**天赋于心（"大理石的花纹"），调和经验论与唯理论。
6. **神正论**：恶的存在与上帝的善相容（最好世界论），伏尔泰《老实人》讥之。

> **立论/易错**：莱布尼茨与斯宾诺莎对立的关键：**多（单子）vs 一（实体）**、**有目的/自由 vs 严格必然**；但他俩都用"预定/必然"解释身心一致。

### Q17 马勒布朗士的偶因论

**答题要点**

1. **偶因（cause occasionnelle）**：身心交互、物体运动都不是真正的因果，只是上帝行动的"机缘"。
2. **在上帝中看见一切**（vision in God）：我们的观念来自与上帝的合一，而非外物印记。
3. **意义**：把笛卡尔的交互难题推向极端，暴露"受造物无真正因果力"的后果——休谟的因果批判与此同源。

## 四、近代经验论

### Q18 ★ 培根：四假相与《新工具》（与亚里士多德《工具篇》对比）

**答题要点**

1. **四假相（idols）**：种族假相（人性以人为尺度）、洞穴假相（个人教养偏见）、市场假相（语言误用）、剧场假相（哲学体系教条）。
2. **《新工具》vs《工具篇》**：亚里士多德的《工具篇》（Organon）是**三段论演绎逻辑**；培根的《新工具》（Novum Organum）是**归纳法**——从经验事实逐级上升到公理（"真正的归纳"），并以"**三表法**"（存在表、差异表、程度表）排除干扰。
3. **知识就是力量**：知识的目的不是思辨而是**征服自然**（"服从自然才能支配自然"）；科学与技术结合。
4. **蚂蚁—蜘蛛—蜜蜂之喻**：经验论者如蚂蚁（只会收集）、唯理论者如蜘蛛（只从自身吐丝），真正的哲学家应如蜜蜂（采集并消化）。
5. **与亚里士多德的分歧**：目的论 vs 机械论、演绎 vs 归纳、静观 vs 效用；但培根并未完全弃绝演绎，只是把归纳置于首位。

> **立论/易错**：华侨 2025 论述就考这个对比——答题要把"**方法的目的与结构**"讲清：亚氏求**证明**（从必然前提到结论），培根求**发现**（从经验到公理）。

### Q19 ★ 霍布斯：自然状态、社会契约与利维坦

**答题要点**

1. **自然状态**："人对人像狼"（homo homini lupus）——因人性自利、欲望无穷、能力相近，故竞争、猜疑、荣誉导致**一切人反对一切人的战争**。
2. **自然权利与自然法**：自我保全是最基本的自然权利；自然法（理性命令）要求放弃部分权利以换和平。
3. **社会契约**：众人把权利**让渡给一个主权者**（利维坦），主权不可分割、不可反抗——为**绝对主权**辩护。
4. **利维坦**：国家是"人造的人"（mortall god），以恐惧维持秩序；主权者不受契约约束（因为契约只在臣民间）。
5. **与洛克之别**：霍布斯让渡**全部权利**、主权不可撤销；洛克只让渡**部分权利**（生命、自由、财产不可让渡），并保留**反抗权**。

> **立论/易错**：霍布斯不是"专制鼓吹者"这么简单——他是在**内战恐惧**下用契约论为秩序找根据；其"自然状态"是**反亚里士多德"人是政治动物"**的近代假设。

### Q20 ★ 洛克：白板说、批判天赋观念、第一性质与第二性质

**答题要点**

1. **白板（tabula rasa）**：心灵本无观念，一切知识来自**经验**（感觉+反省）；"凡在理智中的，无不先在感觉中"。
2. **批判天赋观念**：①天赋观念若存在，应人人共知（实际婴儿、白痴不知）；②"天赋"论者无法说明实践原则的普遍同意（各民族文化差异）；③"天赋"其实是**后天习得而遗忘来源**。
3. **简单观念与复杂观念**：简单观念由感觉/反省被动接受；复杂观念（实体、样式、关系）由心灵组合、比较、抽象而成。
4. **第一性质/第二性质**：第一性质（广延、形状、运动、数目）为物体**固有**，与物体不可分；第二性质（色声香味）为**物体借第一性质在我们心中产生观念的能力**——**不是物体本身的属性**。
5. **人格同一性**：意识（记忆）的连续性构成人格同一。
6. **政治**：《政府论》反菲尔麦君权神授；自然权利（生命、自由、财产）；分权（立法/执行/对外）；反抗权。

> **立论/易错**：洛克第二性质学说是**近代科学实在论与常识知觉的第一次系统分裂**，贝克莱正是抓住这一点走向"存在即被感知"。

### Q21 ★ 贝克莱："存在就是被感知"

**答题要点**

1. **命题**："esse est percipi"——物体的存在就是被感知（或被感知的可能性）。
2. **论证**：①第二性质是主观的（洛克已承认）；②第一性质与第二性质不可分（广延总伴随色、形），故第一性质也主观；③"物质实体"是抽象的、不可感知的虚构——**"物质"是虚无**。
3. **物是观念的集合**：我们对苹果的认识就是色、香、味、形状等观念的集合。
4. **反抽象观念**（批判洛克的抽象三角形）：一切观念都是**具体的**，抽象观念不存在。
5. **上帝保证秩序**：既然未被感知时物体仍存在，是因为**上帝永远在感知**它们——避免唯我论。
6. **回应与影响**：约翰逊踢石头、康德"先验观念论"、现象主义/语义学争论。

> **立论/易错**：贝克莱不是"疯子式唯心主义"，其锋芒是**反物质实体独断论**；他保存常识（物不消失）靠的是上帝，而非人的感知。

### Q22 ★ 休谟：因果关系与怀疑论

**答题要点**

1. **印象与观念**：一切观念都来自印象（"印象在先"）；观念是印象的摹本——**经验主义的意义标准**（无印象对应者无意义）。
2. **因果推理**：我们从未**感知**到"必然联系"，只感知到①接近、②接续、③恒常会合（constant conjunction）；"必然性"是**心灵的习惯性联想**（custom/habit）产生的主观期待。
3. **归纳问题**：从"过去如此"推"将来如此"无**理性**根据（不能诉诸归纳本身，否则循环）；因果推理只有**或然性**。
4. **怀疑论**：①温和怀疑论（生活实践照旧）；②对理性的怀疑（理性无法证明理性）；"休谟之叉"：观念关系（演绎）vs 事实（归纳）。
5. **宗教批判**：《自然宗教对话录》（设计论证的困难）、《论奇迹》（奇迹的证据不可能强于反证据）。
6. **伦理学**：情感主义（道德感），"**是—应当**"问题（事实判断推不出价值判断）。

> **立论/易错**：休谟不是"否定因果"，而是**把因果的必然性从世界挪到心灵**；康德的"哥白尼革命"正是被此题逼出来的（答论述务必接上）。

### Q23 休谟之后：苏格兰常识学派与法国启蒙

**答题要点**

1. **里德/常识学派**：以"常识"驳怀疑论，知觉是**直接实在论**。
2. **伏尔泰**：①经验论与牛顿物理学的普及者；②**自由学说**——意志自由是"根据动机行动的能力"，反对无动机的"绝对自由"，也反对决定论取消道德责任；③自然神论、批判教会（"消灭败类"）。
3. **孟德斯鸠**：《论法的精神》——政体三型（共和、君主、专制）与**三权分立**、地理环境论。
4. **卢梭**：自然状态（自由平等）→私有制导致不平等→社会契约（**公意** general will）→ 自由在于服从自己参与制定的法律；"人生而自由，却无往不在枷锁中"。
5. **18 世纪法国唯物主义**：拉美特利《人是机器》、狄德罗（物质自运动、批判神学）、爱尔维修（功利主义伦理）、霍尔巴赫（机械决定论体系）。

## 五、德国古典哲学

### Q24 ★ 康德的"哥白尼式革命"与先天综合判断

**答题要点**

1. **哥白尼革命**：不是认识**符合对象**，而是**对象符合认识的形式**——"人为自然立法"；主体提供先天形式，经验材料才成为对象。
2. **先天综合判断（如何可能）**：①数学（先验感性论：时空是**直观形式**）；②自然科学（先验分析论：范畴是**知性形式**，先天综合是必然的）；③形而上学（先验辩证论：理性越界使用范畴产生**先验幻相**）。
3. **先验感性/知性/理性**：时空（感性直观形式）→ 范畴+**先验统觉**（"我思必须能够伴随我的一切表象"）→ 理念（灵魂、世界、上帝）。
4. **现象与物自体**：我们只认识**现象**，物自体不可知但可思（"思维无内容是空的，直观无概念是盲的"——参见本库 [[中哲读书感想与笔记]] 对 B75 的引用与"先验/超验"之辨）。
5. **二律背反**：当理性把范畴用于物自体，产生四组正反皆可证的对立（时空有限/无限、单纯/复合、自由/必然、有/无上帝）——**辩证论的消极成果**：划定知识界限。
6. **休谟问题的解决**：因果范畴是知性的**先天形式**，故因果判断具有**客观有效性**（对现象界普遍必然），但这不是物自体的规律。
7. **道德哲学**：绝对命令（普遍化公式、人是目的公式）、善良意志、自律、自由/不朽/上帝作为**实践理性的悬设**。
8. **判断力批判**：美（无利害的愉悦、无概念的普遍性、无目的的合目的性）、崇高（想象力与理性的张力）、艺术（天才）。

> **立论/易错**：康德既不是"唯心论"也不是"经验论"——他**调和**二者：内容来自经验，形式来自主体。答"如何调和经验论与唯理论"时，务必点出「**先天综合判断**」这一台机器。

### Q25 ★ 费希特：自我与非我、知识学三原理

**答题要点**

1. **知识学（Wissenschaftslehre）第一原理**："**自我设定自身**"（我是我）——绝对无条件的行动（Tathandlung），不是事实而是**活动**。
2. **第二原理**："**自我设定非我**"——自我在对立中限制自身，非我是自我活动的产物（理论理性的根据）。
3. **第三原理**："**自我与非我在绝对自我中相互限制/统一**"——可分割性；实践理性由此展开（"自我设定自我是受非我限制的"）。
4. **能动性**：哲学不是解释世界而是**说明自由行动**；"与多""无限努力"（Streben）。
5. **与康德之别**：取消物自体（非我由自我设定），把批判哲学彻底**主观唯心论化**；也把康德的"统觉"变成**生产性行动**。
6. **影响**：谢林（同一哲学）、黑格尔（辩证法）、浪漫派（自我创造世界）。

> **立论/易错**：三原理的顺序与"正—反—合"结构，是黑格尔辩证法的直接前身，这是采分点。

### Q26 谢林的"同一哲学"

**答题要点**

1. **绝对同一（das Absolute）**：主体与客体、精神与自然在绝对者中**无差别地同一**；不是"主体产生客体"，而是二者本为一。
2. **自然哲学与先验哲学**：自然哲学从客体到主体（自然的精神化），先验哲学从主体到客体（精神的自然化）——**两条互补的路径**通向同一绝对。
3. **理智直观/艺术直观**：绝对只能被**审美直观**把握（艺术是哲学的工具）。
4. **与费希特/黑格尔的关系**：不满费希特的"自我"主观性；黑格尔又批评谢林"绝对"是"黑夜中一切牛皆黑"，缺乏**辩证运动**。

### Q27 ★ 黑格尔：实体即主体、辩证法、"真理是一个过程"

**答题要点**

1. **实体即主体**：实体不是静止的"东西"，而是**自我展开、自我认识的过程**（"一切问题的关键在于：不仅把真实的东西理解和表述为实体，而且同样理解和表述为主体"）。
2. **辩证法**：否定之否定（正—反—合）；"**扬弃**"（aufheben）= 否定+保存+提升；矛盾是运动的动力。
3. **真理是过程**："真理是全体"，"真理是一个过程"——真理不是静态命题而精神的自我展开史（《精神现象学》从感性确定性到绝对知识）。
4. **绝对精神**：逻辑学（理念自在）→ 自然哲学（理念异在）→ 精神哲学（理念自为：主观精神—客观精神—绝对精神：艺术、宗教、哲学）。
5. **对康德的批判**：①物自体是"空洞的抽象"（不可知论是独断）；②道德律的形式主义（应加入伦理实体 Sittlichkeit）；③知性（Verstand）不能把握真理，须上升理性（Vernunft）。
6. **主奴辩证法**：自我意识需他者承认；主人通过奴隶获得承认，奴隶通过劳动（对象化）获得自我意识——马克思、科耶夫、萨特的源头。
7. **历史哲学/法哲学**："理性的狡计"、世界历史是自由意识的进展；"凡是合理的都是现实的"。

> **立论/易错**："实体即主体"不是"实体等于人"，而是**本体论上的自我运动**；答"黑格尔如何批判康德"要抓"物自体/形式主义/知性局限"三点。

### Q28 ★ 叔本华与尼采：生命意志、权力意志

**答题要点**

1. **叔本华**：世界是"**意志与表象**"；意志是盲目的生存意志，是一切痛苦的根源（欲求—满足—无聊的循环）；解脱靠审美直观、禁欲、否定意志。受印度哲学与佛教影响。
2. **尼采**：①**权力意志（Wille zur Macht）**——意志的本质不是求生存而是求**增长与超越**（对叔本华的翻转）；②**重估一切价值**、批判基督教道德（奴隶道德 vs 主人道德）、"上帝死了"；③**超人**（Übermensch）与**永恒轮回**（amor fati）；④**酒神/日神**（《悲剧的诞生》）——理性主义批判，艺术形而上学；⑤**视角主义**（没有"无立场的认识"）。
3. **批判理性主义**（华南 2024 简答）：尼采认为理性/逻辑是**保存生命的工具**而非真理的镜子；概念化抹平差异（"一切概念都源于等同化"）；故哲学应回到**生命—身体—生成**。
4. **影响**：海德格尔、福柯、德勒兹；也被民族主义/纳粹曲解（须辨析）。

> **立论/易错**：尼采不是"虚无主义者"，虚无主义是他**诊断**的病症；他的方案是**价值的自我立法**，不是取消价值。

## 六、跨章专题

### Q29 ★ 经验论与唯理论的对立（华侨 2018 论述原题）

**答题要点**

1. **共同前提**：都承认**主客二分**与**知识的确定性追求**（基础主义）；都从"观念"入手。
2. **分歧**：
   - **来源**：经验论（知识源于感觉/反省）vs 唯理论（天赋观念/理性直觉）；
   - **方法**：归纳/观察 vs 演绎/几何学；
   - **实体**：经验论悬置或否定物质实体（贝克莱、休谟）vs 唯理论设定实体（笛卡尔二元、斯宾诺莎一元、莱布尼茨多元）；
   - **真理标准**：清晰明白/逻辑必然 vs 印象对应/习惯。
3. **共同困境**：因果必然性、身心关系、知识与实在的对应。
4. **康德综合**：形式（唯理论）+ 内容（经验论）→ 先天综合判断；现象/物自体之分。
5. **评价**：二者不是简单对立，而是**同一认识论框架内的两条路径**；其争论塑造了整个近代哲学的问题结构。

### Q30 ★ "我思故我在"的哲学史效应（高频论述）

**答题要点**

1. **确立主体**：真理的最终根据从"神/存在"移到"**思维着的我**"——近代哲学的开端（"哲学的第一原理"）。
2. **开启身心问题**：二元论 → 偶因论（马勒布朗士）→ 前定和谐（莱布尼茨）→ 身心平行（斯宾诺莎）→ 现象学（梅洛-庞蒂的身体主体）。
3. **引出怀疑论**：笛卡尔的怀疑方法被休谟推向彻底（自我也只是一束知觉）。
4. **康德回应**：把"我思"改造为**先验统觉**——不是实体的我，而是使经验可能的**形式条件**（批判"理性心理学"的实体化谬误）。
5. **胡塞尔/分析哲学**："我思"作为意向性的起点；分析哲学则以"**我**"的指称问题（罗素、维特根斯坦）重述。

### Q31 ★ 康德的"自在之物"问题（华南 2013 论述）

**答题要点**

1. **含义**：物自体是**独立于认识形式**的存在，不可被直观与范畴规定，故不可知。
2. **功能**：①**限制知识**（防止知性越界）；②为**实践理性**保留地盘（自由、上帝、不朽）。
3. **批评**：①雅可比："没有它不能进哲学，有了它又不能留在哲学里"（自相矛盾）；②黑格尔：空洞抽象；③新康德主义：作为"界限概念"。
4. **当代回响**：实在论/反实在论之争、科学实在论（"不可观察物"）。
